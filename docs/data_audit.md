> 이 문서는 방언 지식 베이스(C_kb) 구축 과정의 **재현 가능한 감사 기록**이다.

## 3. 규칙 DB 스키마

JSONL 한 줄 = 한 규칙. 필드:
`region` · `category` · `standard_form`(검색 매칭 대상) · `dialect_form`(주입 대상) ·

⚠️ `category`는 **권역별로 라벨 체계가 다름**(강원=종결어미/격조사, 경상=음운론/문법론/

### 4-1. malformed 검수 결과 (2026-07-27, 사용자+협업) — `rule_overrides.json`
판단 기준: **형태→형태 변환 규칙인가 vs 방언 특징 서술인가.** 10건 처리:

  부정 `못→몬/몯`. explanation은 맥락으로 유지.
- **유지 2**(#1 경어법 하십시오체→하이소체, #10 충청 -(으)ㄹ래?→-ㄹ려?): 길이 오탐, 정상 규칙.

## 5. 검색기(C_kb)와 커버리지 관찰 — `src/retrieval/kb_retriever.py`

- 표준어 문장을 쿼리로, 권역별 분리 색인에서 어휘·규칙을 각각 검색해 주입.
  어휘=내용어(명사·동사·형용사) 단어 치환, 규칙=조사·어미·음운 변환으로 **역할 분담**.
- z/ 프로젝트의 순수 BM25·형태소 토크나이저를 복사(vendoring). z는 동결 보존.

**핵심 관찰 — 이 도메인의 방언색은 어휘가 아니라 문법이 만든다**:
악취 민원은 현대 행정 어휘(공장·폐수·민원·머리)가 대부분이고 이들은 방언에서도
표준어와 같아 방언 사전에 없다. 실측(쿼리 "공장 폐수 냄새 때문에 머리가 너무 아파요")에서
내용어 5개 중 어휘 매칭은 '냄새' 1개뿐. → **어휘 치환 적중률은 구조적으로 낮고, 방언색은
어미·조사·음운(규칙 DB)이 지배**할 것으로 예측. RQ2에서 '규칙 > 어휘' 가설로 검증 가능.

- RAG는 보강(augment)이지 덮어쓰기가 아님: 미매칭 부분은 프롬프트에 없으므로 **LLM 자체
  파라미터 지식으로 출력**. → coverage(검색 적중률)가 낮으면 C_kb ≈ C0로 수렴하므로,
  **검색 로그로 coverage를 재는 것이 핵심 진단 지표**.

## 6. 파일럿 관찰 (S1×C0, Qwen3.6-27B, 2026-07-27)

경상·전라 8시나리오, 상용 키 부재로 로컬 Qwen만 실행(8/8 성공, ~7초/대화).
- 형식 안정, 존댓말 유지(민원인 존댓말 강제 규칙 추가 후).

## 6-2. S2 파일럿 관찰 (C0 vs C_kb, Qwen, 2026-07-27, n=2)

`src/generation/s2_pipeline.py`로 경상·전라 2건. 어휘 coverage 경상 0.31 / 전라 0.50.
- **① C_kb가 검색 지식을 실제 주입(추적 가능)**: 냄새→냄섀(경상), 창문→창때기·
  심하다→짝잘허다·냄새→남새(전라)가 출력에 그대로 등장. C0엔 없음.
- **② C_kb가 권역을 교정(핵심 가설 지지)**: 전라 s2에서 C0는 경상 어미(~니더/~거라)로
  누수, C_kb는 전라(창때기/짝잘허서/부텀)로 교정됨.
- **③ 트레이드오프**: C_kb는 방언성↑이나 문자단위 오염↑(잇습니다/허디기 등 과잉
  음운표기)로 유창성↓. → 삼각 평가(방언성 vs 의미보존/유창성)가 판정할 지점.
- **④ ①단계 오염 전파**: 표준어 생성에 외국어 누수(中 '那股')가 섞여 C0·C_kb 공통 상속.
  → ①단계 품질도 관리 대상.
- 튜닝 여지: k(주입량) 조절, 변환 프롬프트에 과잉 음운표기 억제 지시.

### 6-2b. S2 파일럿 확대 (n=8, 프롬프트 튜닝 후, 2026-07-27)
경상·전라 4건씩. 어휘 coverage 평균 0.31(경상 0.21~0.35 < 전라 0.32~0.39).
프롬프트 튜닝(외국어 금지 + 표준철자 유지) 효과는 **부분적**:
- 외국어 누수: ①단계 표준어에 3/8 잔존('specifically','请尽快','开窗'). Qwen 모델 한계로
  프롬프트만으론 완전 차단 불가 → 탐지 후 재생성/후필터 필요.
- 과잉 음운표기: 완화되나 잔존('잇이다','쎅힌'). 표준철자 유지 지시가 부분적으로만 작동.
n=2 관찰이 n=8에서 재확인:
- C_kb가 KB 지식을 일관 주입(짝잘허다/남새/내굼새/창때기 반복 출현, C0엔 없음).
- C_kb가 권역 일관 교정+방언 강화(전라 당께/요잉/십더). C0은 약하고 충청 '~유' 누수도.
- 트레이드오프(방언성↑ vs 표기정확↓) 확정 → 삼각 평가로 정량화 필요.
- 27B가 강한 방언 지시에 단어 뭉갬('악입니다'=앞이, '화약적'=화학적) → 약한 모델 방증.

### 6-2c. Claude(상용) C0 vs C_kb — 같은 8시나리오 (2026-07-27)
- **Claude C0가 이미 유창한 전라 방언**(여그/냄시/징하게/랑께요/구만요). 지식 없이도 우수.
- Claude C_kb는 KB 어휘 반영(내굼새/짝잘허다/창때기)하나 C0가 이미 좋아 **한계이득 작음**.
- **중심 발견: RAG 가치 ∝ 1/베이스모델 성능.** 약한 Qwen엔 C_kb가 방언성·권역을 크게
  개선(유창성 비용), 강한 Claude엔 C0로 충분해 C_kb 여지 작음. → RAG 필요처=약한 모델.
- ⚠️ **RAG 비단조성 신호**: '앞짝→악짝'(앞→악)이 Qwen·Claude 둘 다 C_kb에서만 출현 →
  KB에 의심 항목 존재 가능(어휘 검수 단서). 향후 추적.

## 8. 평가 프레임워크 설계 (결정 사항, 2026-07-29)

> **[역할]** 평가의 **상위 설계 SSOT는 `research_scope.md` §7**(속성별 역할분담·삼각 구조·통계).
> 이 §8은 그 구현 결정 = B/C/A 세부·방언성 표지 손목록·근거(provenance)·진행 상태를 담는다.

목표: 사람/방언심판 없이도 생성 방식(C0/C1/C_kb × 모델)을 **신뢰성 있게 순위매기는 검증된
평가**. 평가 방법 자체를 기여로 삼음(research_scope §7·§11(B)와 연결).

**채택 야심 수준 = (2): B + C + A** (구현 순서도 B→C→A).
- **B. 방언성 이중추정**: 규칙기반, LLM 안 씀. 정의 = **그 권역 표지 (+), 타권역 표지 (−)**.
  층위 = **종결어미·조사(문법표지)** 중심(도메인 방언색이 어미에 몰림). 잣대는 **(다) 두 버전
  비교**: ① 손으로 만든 독립 고정밀 표지목록, ② KB(grammar_rules) 파생 표지목록 → 두 잣대의
  **불일치를 진단 신호**로. (①만 쓰면 누락 위험, ②만 쓰면 C_kb에 불공정 → 둘 다.)
- **C. 역번역 복원성**: 방언→표준어 역번역이 의미 복원하면 정상 방언, 실패하면 오염 → 방언과
  노이즈 분리(Qwen 과잉표기 문제 대응). 모델 필요.
- **A. 합성 교란 검증**: 알려진 오류(타권역 어미·미변환·의미훼손) 통제 주입 → 각 지표의 민감도/
  특이도를 사람 라벨 없이 측정 → 지표 신뢰성 입증(핵심 novelty).

**순환성 회피 원칙(중요)**:
- 방언성 채점에 **RAG DB 그대로 쓰면 C_kb에 불공정**(주입한 답 베꼈는지 재는 꼴) → 독립 손목록을
  주 잣대로, KB버전은 부잣대로 병기.
- **LLM으로 방언 채점 금지**(LLM이 방언 모름=우리 문제 → 순환, +자기편애). LLM은 담화 judge에만,
  그것도 생성모델과 다른 모델로.

**방언성 표지 손목록(초안, 미확정)** — 정식 표로 이관: **`docs/dialect_markers.csv`**(2026-07-30 생성,
5권역 42표지: 경상11·전라9·충청8·강원5·제주8·공용1). 초안은 **LLM 지식 기반 `[저자판단]`**(문헌 미검증) → 국립국어원 대조로 출처·등급 채우는 중
(2026-07-31 우리말샘 5권역 1차 대조 완료: **11/42 `[출처있음]`** — 경상5·전라3·충청1·강원1·제주1.
전부 permalink 열람검증. 정정 2건: '-꼬'=「옛말」강등, '-니껴'=강원→경상 재배정. '-유'(충청)·'-수다/수과/마씀'(제주)
등 대표 어미가 우리말샘 미등재 → 지역어 종합정보/문헌 필요).
**[출처있음]은 permalink(우리말샘 sense_no) 열람검증 후에만 부여**(검색페이지 추출은 오류 발생 — 경상
'-꼬'가 실제론 「옛말」이라 강등된 사례). **지역어 종합정보(dialect.korean.go.kr)는 JS 포털이라 자동
도구로 결과 회수 불가 → 사용자가 브라우저로 대조**; 어미 표지는 우리말샘 미등재가 많음(경상 적중률 5/11). 역할: `+`(그 권역) / `−`(타권역 누수, 코드 자동계산) / `0`(중립) / `x`(가짜·안티표지, 예 ~드래).

**코퍼스 주도 v2 백본 (2026-07-31) — `docs/dialect_markers_v2.csv`, 재현 스크립트 `src/eval/extract_corpus_markers.py`**:
AI-Hub 중·노년 방언(2인발화, 권역별 라벨; 외부 데이터·gitignore)에서 형태소 기반으로 (표준꼬리→방언꼬리)
어미·조사 변환을 추출, 5권역 교차 집계로 **점유율 기반 변별력 + 레지스터(존대/반말/중립) + 연령경향**을
태깅(1,754 표지쌍, 유의미분은 상위 ~150). 성과: (1) **광역공유(믄/먼/여/애요 등)=저변별 → +표지 부적합을
데이터로 식별**(손목록 순수성 문제 해결), (2) 권역 고유 표지 식별(경상 서→가/가꼬·요→예, 충청 요→유·슈,
전라 데→디·으니까→응께, 제주 고→엉·지→주게·면서→멍·습니다→수다), (3) **사전 오류 재정정**: 제주 '수다'
(우리말샘=함경)·충청 '유/슈'(우리말샘 미등재)를 코퍼스가 확증. 한계: 경상·강원만 고령(69·65), 충청·전라·제주는
중년(≈49); 존대 종결은 경상 고령에서만 풍부(존대 문장 50%), 제주 존대(~수다/수과)는 표본 얇음→문헌 보강.
**채점용 손목록 = `docs/dialect_markers_scoring.csv`** (재현 `src/eval/build_scoring_markers.py`): v2에서
**존대·중립 + 변별 + 빈도≥8** 선별, 표지족(주권역/표준꼬리)으로 이형태 묶음, 레지스터는 **표준 꼬리 기준**
판정(반말 제외), 우리말샘은 **정확일치 보조 플래그**로만(근거 우선순위: 코퍼스 1차 > 우리말샘 최후). 채점포함 70개
(경상20·제주23·전라17·충청6·강원4). 특성: **문법 방언성은 주로 연결어미/조사 이형태(서→가, 데→디, 니까→응께/난,
면→…)와 소수 존대 종결(요→예/유/라, 습니다→수다)이 담당.** 확정 한계(문서화): (a) **`~소`(아요/어요→소) = 전라·강원 공용 방언표지로 확정**(사용자
판정 + 코퍼스 강원6/전라7). 우리말샘은 표준 하오체(일반어)로 보나 사용역상 방언으로 채택 — 단 표준 하오체와
형태 동일해 **누수(−) 계산 시 하오체 일반문 오검출 유의.** (b) **강원 방언성은 억양(운율) 중심 → 텍스트로는
과소측정**되는 구조적 한계(텍스트 표지는 `~래요/~소` 정도). (c) **연령 불균형**(경상·강원 고령 / 충청·전라·제주
중년 ≈49)은 데이터 수집 한계 — 표지 '타당성'엔 무관하나 권역 간 '빈도' 직접비교 시 유의.

**B 채점기 구현·검증 (2026-07-31) — `src/eval/score_dialectness.py`**: (표준↔방언) 정렬 어절쌍에서 변환을
손목록에 대조해 타깃권역 +표지 / 타권역 −누수를 센다(표면 문자열 매칭이 아니라 '정렬된 변환' → 조사 '가' 등
단형 오탐 회피; S2 파이프라인이 정렬 제공). **코퍼스 5권역 교차검증(혼동행렬, +표지/1000세그먼트): 대각선이
전 권역 최대**(경상 7.7·제주 20.4 뚜렷 / 충청 4.3·전라 3.8은 상호 혼동 다소 = 디·여 공유 / **강원 0.3 = 한계적,
방언 옅음 재확인**). → 사람 라벨 없이 지표의 권역 변별력 실증(경량 A). **이중추정(①vs②) 완성 (2026-07-31)**: ② RAG-KB(grammar_rules) 파생 잣대 추가(어미·조사 규칙만; 경상146·강원25·
충청89·전라34·**제주0=KB 부재**). 코퍼스 혼동행렬 대각지배: **① 코퍼스 5/5(강함) vs ② KB 2/5**(경상·충청만; 강원·전라
약, 제주 N/A). → **두 잣대 불일치가 KB의 방언성 측정 부적합(음운편중·나무위키·제주부재)을 정량 확인** = 코퍼스 1차
결정 정당화. 논문 프레이밍: 수렴권역(경상·충청)=고신뢰 / ②실패=KB 커버리지 한계(지표 실패 아님). **①=운영 지표,
②=진단·수렴 보조.**

**생성물 채점 (step3, 2026-07-31) — `src/eval/score_generated.py`**: S2 출력(C0 vs C_kb)을 **diff 정렬**(어절 밀림 방지)
후 **문법 축(어미, B) + 어휘 축(vocab_clean)** 을 분리 채점. 4권역(경상·전라 기존 + 충청·강원 신규 Qwen 생성)
결과(대화당 +표지 평균): **어휘 축 C_kb 전권역 압승**(경상 1.5→4.8·전라 1.2→5.5·충청 0→1.2·강원 0.2→2.0),
**합계도 4권역 모두 C_kb>C0**. 문법 축은 **경상만 C0>C_kb**(Qwen이 경상 말끝 이미 잘 뽑음=강한 베이스), 전라는
C_kb승, 충청·강원은 0(방언 옅음/손목록 얇음). → **예비 RQ2: RAG 이득 = 주로 어휘(전권역 일관), 문법 = 권역
