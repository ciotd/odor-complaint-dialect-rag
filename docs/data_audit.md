# 방언 지식 리소스 감사·정제 기록 (data audit)

> 이 문서는 방언 지식 베이스(C_kb) 구축 과정의 **재현 가능한 감사 기록**이다.
> 논문 Methods / 한계 절의 근거로 쓴다. 확정 설계는 `research_scope.md`,
> 논의 로그는 리포 밖 `논문계획_회의정리(26.07.24).md`(SSOT)를 참조.
> 최종 갱신: 2026-07-27.

## 1. 리소스 출처 (provenance)

| 리소스 | 출처 | 생성 방식 |
|---|---|---|
| 어휘(vocab) | 네이버 방언 사전 | 웹 스크래핑 |
| 문법(grammar) | 나무위키·논문 등(PDF) | 문서 수집 후 **LLM으로 메타데이터 구조화** |

- 어휘는 **방언형이 표준어와 다른 단어만** 수록(사전의 성격). 공장·머리·폐수처럼
  방언에서도 표준어와 같은 현대 어휘는 애초에 없다 → 5장 커버리지 논의 참조.
- 문법은 LLM 구조화 산물이므로 **구조적 오류·정확성 미보장**. 아래 정제·검수 대상.

### 라이선스 방침 (미정, 확인 필요)
- 원자료(`RAG_resource/`)와 정제 결과(`data/dialect_kb/`)는 **저장소에 올리지 않음**
  (`.gitignore`). 특히 **나무위키 출처의 라이선스 처리 방침은 투고 전 확정 필요**.
- 공개는 **방법·스크립트만**, 데이터는 비공개 유지가 현재 방침.

## 2. 정제 (clean) — `src/preprocess/clean_resources.py`

입력 `../RAG_resource/` → 출력 `data/dialect_kb/`(gitignore). 4권역(강원·경상·전라·충청),
제주 제외(research_scope 4장).

### 어휘 정제 (결과: `vocab_clean.jsonl`, 56,064개)
| 권역 | 입력 | 유지 | 무변환 | 속담 | 중복 | 표제어없음 |
|---|---|---|---|---|---|---|
| 강원 | 13,812 | 13,584 | 4 | 0 | 224 | 0 |
| 경상 | 11,313 | 11,304 | 0 | 1 | 8 | 14 |
| 전라 | 26,604 | 24,533 | 465 | 34 | 1,572 | 651 |
| 충청 | 6,745 | 6,643 | 0 | 0 | 102 | 105 |

- `standard`를 `head`(표제어)+`gloss`(뜻풀이)로 파싱. 무변환(표제어==방언형·뜻풀이없음)·
  속담(문장형)·중복 제거.
- 파싱 휴리스틱 한계: 초기 `_DEF_TAIL` 정규식이 '가래나무' 등 정상 명사를 뜻풀이로
  오분류(표제어없음 1320→770) → 해당 규칙 제거로 수정. 남은 '표제어없음'은
  '단단히 / 확실히'처럼 슬래시 다의어라 정상.

핵심 결정:
- **예문대조규칙(경상 79건) 제외**: `standard_form`/`dialect_form`이 통째로 문장인
  예문 쌍. 검색소스에 들면 '미리 만든 few-shot 검색'이 되어 C1과 C_kb 구분이 붕괴
  (research_scope 5.1). 버리지 않고 `grammar_examples.jsonl`로 이관(참조·평가용).
- **당께라우 제외**(전라, 1건): 현지인 확인 결과 실사용 빈도 낮음(2026-07-24).
- 강원 문법 2파일 병합 시 `(dialect_form, explanation[:40])` 키로 중복 제거.

## 3. 규칙 DB 스키마

JSONL 한 줄 = 한 규칙. 필드:
`region` · `category` · `standard_form`(검색 매칭 대상) · `dialect_form`(주입 대상) ·
`explanation`(주입 페이로드) · `keywords`(검색 훅).

⚠️ `category`는 **권역별로 라벨 체계가 다름**(강원=종결어미/격조사, 경상=음운론/문법론/
연결어미/구절관용구, 충청=음운-모음변화 등). 출처가 달라 **통일 분류 아님** → 한계로 기록.

## 4. 발견된 품질 이슈 (검수 대상)

전수 검수 대상은 규칙 294개(사람이 1~2시간 내 가능). 어휘 56k는 전수 불가 → 표본·규칙기반.

**아직 규칙 294개 전수 검수는 완료되지 않았다.** 지금까지는 (a) 메타데이터 기반 구조적
정제 + (b) 권역별 표본 eyeball만 수행. 자동 플래그로 의심 항목을 좁혀 검수 예정.

검수용 산출물: `data/dialect_kb/grammar_rules_review.csv` (gitignore) —
`src/preprocess/export_rules_review.py`로 생성. 플래그 분포(294행):

| flag | 수 | 의미 |
|---|---|---|
| (없음) | 229 | 특이사항 없어 보임(그래도 확인 권장) |
| `malformed` | 10 | `dialect_form`에 형태가 아니라 서술문이 든 필드 어긋남. **주입 시 해로움** → 제거/수정. 경상 음운론·문법론에 집중(예: '성조 체계'→'동남방언은 성조방언…') |
| `templated_exp` | 44 | explanation이 '…에 대응하는 … 형태소 … 입니다' 자동 템플릿. 형태쌍은 맞지만 정보량 낮음 |
| `question_only` | 11 | standard_form이 의문형뿐 → 평서문 쿼리에 안 걸림(경상 편중 진단용) |

기타 관측:
- **경상 규칙이 의문·연결어미에 편중** → 평서문 쿼리에 off-target 검색(예: '심해서'에
  '-는가요?→-는교?'가 나옴). 권역별 규칙 수 불균형(강원 25 / 전라 41)도 존재.

### 4-1. malformed 검수 결과 (2026-07-27, 사용자+협업) — `rule_overrides.json`
판단 기준: **형태→형태 변환 규칙인가 vs 방언 특징 서술인가.** 10건 처리:
- **제거 3**(경상 음운론 서술형 — 모음체계/성조/모음조화 지역차): 형태매핑이 아니라
  주입 불가한 배경지식.
- **수정 5**(경상 문법론 — 설명에 파묻힌 형태쌍만 추출): 주격 `-이/가→-이가,-(이)란`,
  속격 `-의→-에/-으/-이/-오/-우`, 공동격 `-와/-과→-카/-캉`, 선어말 `-았-,-겠-→-앗-,-것-`,
  부정 `못→몬/몯`. explanation은 맥락으로 유지.
- **유지 2**(#1 경어법 하십시오체→하이소체, #10 충청 -(으)ㄹ래?→-ㄹ려?): 길이 오탐, 정상 규칙.
- 결과: 규칙 294→**291**. 결정은 `rule_overrides.json`에 명시되어 `clean_resources.py`가
  정제 시 자동 적용(재현 가능).

## 5. 검색기(C_kb)와 커버리지 관찰 — `src/retrieval/kb_retriever.py`

- 표준어 문장을 쿼리로, 권역별 분리 색인에서 어휘·규칙을 각각 검색해 주입.
  어휘=내용어(명사·동사·형용사) 단어 치환, 규칙=조사·어미·음운 변환으로 **역할 분담**.
- z/ 프로젝트의 순수 BM25·형태소 토크나이저를 복사(vendoring). z는 동결 보존.

**핵심 관찰 — 이 도메인의 방언색은 어휘가 아니라 문법이 만든다**:
악취 민원은 현대 행정 어휘(공장·폐수·민원·머리)가 대부분이고 이들은 방언에서도
표준어와 같아 방언 사전에 없다. 실측(쿼리 "공장 폐수 냄새 때문에 머리가 너무 아파요")에서
내용어 5개 중 어휘 매칭은 '냄새' 1개뿐. → **어휘 치환 적중률은 구조적으로 낮고, 방언색은
어미·조사·음운(규칙 DB)이 지배**할 것으로 예측. RQ2에서 '규칙 > 어휘' 가설로 검증 가능.

- RAG는 보강(augment)이지 덮어쓰기가 아님: 미매칭 부분은 프롬프트에 없으므로 **LLM 자체
  파라미터 지식으로 출력**. → coverage(검색 적중률)가 낮으면 C_kb ≈ C0로 수렴하므로,
  **검색 로그로 coverage를 재는 것이 핵심 진단 지표**.

## 6. 파일럿 관찰 (S1×C0, Qwen3.6-27B, 2026-07-27)

경상·전라 8시나리오, 상용 키 부재로 로컬 Qwen만 실행(8/8 성공, ~7초/대화).
- 형식 안정, 존댓말 유지(민원인 존댓말 강제 규칙 추가 후).
- **방언 품질 약함/불안정**: 절반은 표준어에 가깝고, 방언 시 권역 혼재(경상에 충청·강원
  어미 누수). 외국어 누수(일본어 '前から', 영어 'lately'), 금지어('~로 접수하겠습니다')
  위반. → 약한 로컬 모델이라 **C_kb 개입 여지가 크다**(상용은 C0도 이미 준수 — z 관찰).

## 6-2. S2 파일럿 관찰 (C0 vs C_kb, Qwen, 2026-07-27, n=2)

`src/generation/s2_pipeline.py`로 경상·전라 2건. 어휘 coverage 경상 0.31 / 전라 0.50.
- **① C_kb가 검색 지식을 실제 주입(추적 가능)**: 냄새→냄섀(경상), 창문→창때기·
  심하다→짝잘허다·냄새→남새(전라)가 출력에 그대로 등장. C0엔 없음.
- **② C_kb가 권역을 교정(핵심 가설 지지)**: 전라 s2에서 C0는 경상 어미(~니더/~거라)로
  누수, C_kb는 전라(창때기/짝잘허서/부텀)로 교정됨.
- **③ 트레이드오프**: C_kb는 방언성↑이나 문자단위 오염↑(잇습니다/허디기 등 과잉
  음운표기)로 유창성↓. → 삼각 평가(방언성 vs 의미보존/유창성)가 판정할 지점.
- **④ ①단계 오염 전파**: 표준어 생성에 외국어 누수(中 '那股')가 섞여 C0·C_kb 공통 상속.
  → ①단계 품질도 관리 대상.
- 튜닝 여지: k(주입량) 조절, 변환 프롬프트에 과잉 음운표기 억제 지시.

### 6-2b. S2 파일럿 확대 (n=8, 프롬프트 튜닝 후, 2026-07-27)
경상·전라 4건씩. 어휘 coverage 평균 0.31(경상 0.21~0.35 < 전라 0.32~0.39).
프롬프트 튜닝(외국어 금지 + 표준철자 유지) 효과는 **부분적**:
- 외국어 누수: ①단계 표준어에 3/8 잔존('specifically','请尽快','开窗'). Qwen 모델 한계로
  프롬프트만으론 완전 차단 불가 → 탐지 후 재생성/후필터 필요.
- 과잉 음운표기: 완화되나 잔존('잇이다','쎅힌'). 표준철자 유지 지시가 부분적으로만 작동.
n=2 관찰이 n=8에서 재확인:
- C_kb가 KB 지식을 일관 주입(짝잘허다/남새/내굼새/창때기 반복 출현, C0엔 없음).
- C_kb가 권역 일관 교정+방언 강화(전라 당께/요잉/십더). C0은 약하고 충청 '~유' 누수도.
- 트레이드오프(방언성↑ vs 표기정확↓) 확정 → 삼각 평가로 정량화 필요.
- 27B가 강한 방언 지시에 단어 뭉갬('악입니다'=앞이, '화약적'=화학적) → 약한 모델 방증.
