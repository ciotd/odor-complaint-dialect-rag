## Ⅲ. 제안 방법

### 1. 제안 방법 개요

본 연구의 목표는 상용 API에 의존하지 않고 로컬 오픈소스 대규모 언어 모델(large language model,
LLM)만을 이용하여 5개 권역(경상·전라·충청·강원·제주)의 방언 악취 민원 상담 대화를 합성하고, 그
과정에서 외부 방언 지식을 어떤 방식으로 공급하는 것이 효과적인지를 규명하는 것이다.

상용 LLM은 방대한 웹 말뭉치로 학습되어 방언 표현에 대한 내재 지식이 비교적 풍부하나, 지속적 호출
비용과 민원 데이터의 외부 전송, 그리고 모델 버전·정책 변경에 따른 장기적 재현성 문제를 수반한다.
반면 로컬 오픈소스 모델은 이러한 문제에서 자유롭지만 방언 내재 지식이 부족하여, 방언이 거의 실현되지
않거나 인접 권역의 어미가 혼입되는 등의 품질 저하가 나타난다. 본 연구는 이 격차를 **외부 방언 지식의
검색·주입(retrieval-augmented generation, RAG)**으로 보완할 수 있는지를 검증한다.

제안 시스템의 전체 구조는 그림 1과 같다. 입력은 악취 민원 시나리오를 구성하는 구조화된 키워드
슬롯(냄새 종류, 민원인 위치, 냄새 강도 변화, 지속 시간, 원인 추정 지역)이며, 출력은 상담원과 민원인
사이의 8~10턴 상담 대화이다. 상담원 발화는 표준어로, 민원인 발화는 해당 권역의 방언으로 생성한다.
시스템은 (1) 방언 지식을 공급하는 방식을 달리하는 **지식 공급 조건**, (2) 방언을 생성하는 절차가
다른 **두 생성 파이프라인(S1, S2)**, 그리고 (3) 인간 평가 없이 생성 결과의 방언성을 진단하는 **자동
평가 지표**의 세 축으로 구성된다. 이하 각 구성요소를 차례로 기술한다.

**그림 1.** 제안 시스템의 전체 구조
Fig. 1. Overall architecture of the proposed system.
```
                         ┌───────────── 지식 공급 조건 ─────────────┐
 키워드 슬롯 ──▶ [프롬프트] │ C0(없음) / C1(예시) / C_kb(RAG) / C_kb+C1 │ ──▶ [로컬 LLM]
   (5개)                  └──────────────────────────────────────┘        │
                                RAG DB(어휘·문법) ─검색─▲                    │
                                                                          ▼
       S1: 키워드 → (지식주입) → 방언 대화 직접 생성                  방언 대화
       S2: 키워드 → 표준어 대화 → (표준어 질의로 검색·주입) → 방언 변환   │
                                                                          ▼
                        자동 평가: 방언율·누수율(B) + 지표 신뢰성 검증(A)
```

### 2. 검색 증강 생성 기반 방언 지식 주입

가. 방언 지식의 두 층위

표준어와 방언의 차이는 크게 두 층위에서 나타난다. 첫째는 **어휘 층위**로, 동일한 지시 대상을 서로
다른 단어로 표현하는 경우이다(예: 표준어 "냄새" ↔ 방언 "내굼새"). 둘째는 **문법 층위**로, 어미·조사·
활용형이 달라지는 경우이다(예: 표준어 종결어미 "-어요" ↔ 경상 방언 "-어예"). 방언성을 충실히
구현하려면 두 층위의 지식이 모두 필요하므로, 본 연구는 검색 대상 지식베이스를 **어휘 자원**과 **문법
규칙 자원**으로 나누어 구축하였다.

나. 어휘 자원과 검색

어휘 자원은 웹 사전을 수집하여 LLM으로 `{표준어, 방언형, 품사}` 형태로 구조화한 것으로, 5개 권역에
대해 각각 수천에서 수만 개 규모의 표제어를 확보하였다. 어휘는 표제어라는 명확한 조회 키를 가지므로,
검색은 **표제어 정확 매칭**으로 수행한다. 즉 질의 문장에서 명사·용언 등 내용어를 추출·원형 복원한 뒤
지식베이스의 표제어와 정확히 일치하는 항목의 방언형을 반환한다. 이는 BM25와 같은 근사 검색이
유발하는 무관 항목 혼입을 방지한다.

다. 문법 규칙 자원과 검색

문법 규칙 자원은 방언학 문법서 및 웹에서 수집한 문법 정보를 `{표준형, 방언형, 설명, 예문}` 형태로
구조화한 것이다. 문법 규칙은 어미·활용과 같이 형태 변이가 크므로, 검색은 질의를 형태소 분석한 뒤
**BM25**로 관련 규칙을 순위화한다. 다만 존댓말·종결어미·조사와 같이 방언성 실현에 핵심적이면서
도메인 전반에 보편적으로 쓰이는 규칙은 질의 문장에 따라 누락되기 쉬우므로, 해당 범주의 규칙은 질의와
무관하게 항상 주입하도록 하였다.

라. 프롬프트 주입

검색된 어휘·규칙은 다음과 같이 구조화된 텍스트로 변환하여 프롬프트의 지식 블록에 삽입한다. 이때
문법 규칙에는 해당 규칙의 예문을 함께 제시하여, 추상적 규칙만 제시할 때보다 모델이 규칙을 적용하기
쉽도록 하였다(본 연구의 예비 실험에서 예문을 병기했을 때 방언 실현이 유의하게 향상됨을 확인하였다).

```
[방언 어휘]
- '냄새' → 내굼새 / 내음새
[방언 문법 규칙]
- 해요체 어미 -어요 → -어예 (표준 해요체에 대응) [예: 좋아요→좋아예]
```

### 3. 생성 파이프라인

동일한 시나리오·조건에 대해 방언 생성 절차가 다른 두 파이프라인을 비교한다. 두 파이프라인은 상호
배타적 대안이 아니라, 지식 검색이 성립하는 정도가 서로 달라 상보적으로 분석된다.

가. 직접 생성 (S1)

키워드 슬롯으로부터 방언 대화를 한 단계로 직접 생성한다. 생성 이전에는 검색 질의로 삼을 수 있는
표준어 문장이 존재하지 않으므로, 질의로는 시나리오 키워드(냄새 종류·위치)를 사용한다. 이 경우 어휘
검색은 질의에 포함된 소수의 내용어에만 적용되고 문법 규칙은 앞서 기술한 고정 주입이 지배적이므로,
S1의 지식 공급은 사실상 **고정 주입(injection)**의 성격을 띤다.

나. 2단계 변환 (S2)

먼저 표준어 상담 대화를 생성한 뒤, 생성된 민원인 표준어 발화를 질의로 하여 방언 지식을 검색·주입하고
이를 방언으로 변환한다. 질의가 실제 문장이므로 어휘 검색의 적용 범위가 S1보다 넓어 **질의 기반
검색(retrieval)**이 성립한다. 다만 변환 단계는 표준어 문장의 의미를 보존해야 하는 제약이 있어, 주입된
지식이 이 제약과 상호작용하는 정도가 S1과 다를 수 있다.

### 4. 지식 공급 조건

방언 지식을 공급하는 방식을 표 1의 네 가지 조건으로 구분한다. 이는 "예시 제공"의 효과와 "지식 검색·
주입"의 효과를 분리하여 측정하기 위함이다.

**표 1.** 지식 공급 조건
Table 1. Knowledge injection conditions.

| 조건 | 공급 지식 | 분리 대상 |
|---|---|---|
| C0 | 없음(금지 규칙만) | 기준선(zero-shot) |
| C1 | 고정 few-shot 예시 | 예시 제공 효과 |
| C_kb | RAG(어휘+문법 규칙+예문) | 검색·주입 지식 효과 |
| C_kb+C1 | RAG + few-shot 예시 | 결합 효과 |

C1은 완결된 방언 대화 예시를 제시하는 조건으로, 품질 향상이 "지식 검색" 때문인지 단지 "예시가
제공되었기" 때문인지를 분리하는 필수 대조군이다. C1을 포함하지 않으면 RAG의 고유 기여를 입증할 수
없다. 모든 조건에서 키워드, 프롬프트 구조, 출력 형식, 생성 파라미터, 검색 파라미터를 동일하게 고정하여
공정 비교를 보장한다.

### 5. 자동 진단 지표

방언 화자에 의한 인간 평가가 어려운 상황을 전제로, 조건 간 방언성을 상대 비교하기 위한 자동 지표를
설계한다. 지표는 방언성을 측정하는 B 단계와, 그 지표 자체의 신뢰성을 검증하는 A 단계로 구성된다.

가. 방언성 지표 (B 단계)

방언 표지(marker)는 방언 발화 코퍼스에서 (표준어 종결어미, 방언 종결어미)의 변환쌍을 추출하여
구성한다. 각 변환쌍의 권역별 출현 빈도와 변별력을 기준으로 필터링하여 표지 목록을 확정한다. 권역 $r$의
생성문 $\hat{y}$에 대한 방언성 점수는 식 (1)과 같이 정의한다.

$$D(\hat{y}, r) = \frac{1}{|\hat{y}|}\left(\sum_{m \in M_r^{+}}\mathbb{1}[m \in \hat{y}] - \sum_{m \in M_r^{-}}\mathbb{1}[m \in \hat{y}]\right) \quad (1)$$

여기서 $M_r^{+}$는 권역 $r$의 방언 표지 집합, $M_r^{-}$는 타권역 표지 집합, $\mathbb{1}[\cdot]$은 지시함수,
$|\hat{y}|$는 민원인 발화의 어절 수이다. 구현에서는 이를 두 지표로 분리하여 보고한다. **방언율**은 타깃
권역 표지 적중 수를 총어절로 나눈 값으로 해당 권역 방언을 실현한 정도를, **누수율**은 타권역 표지 적중
수를 총어절로 나눈 값으로 인접 권역 어미가 혼입된 정도를 나타낸다.

나. 지표 신뢰성 검증 (A 단계)

제안 지표가 실제 방언성에 타당하게 반응하는지를 인간 라벨 없이 검증하기 위하여, 정상 생성문에 통제된
오류를 주입한 교란문에 대한 지표의 반응을 측정한다. 교란은 채점기(표지 목록)와 독립인 참조 모델을
이용하여 두 방식으로 수행한다. 첫째, **표준어화**는 방언을 표준어로 되돌리는 것으로, 이때 방언율이
크게 하락하면 지표가 방언 제거를 민감하게 탐지함을(민감도) 의미한다. 둘째, **타권역화**는 다른 권역
방언으로 변환하는 것으로, 이때 원 권역 방언율이 하락하고 누수율이 상승하면 지표가 타권역 오염을
분별함을(특이도) 의미한다. 교란기와 채점기가 독립이므로 채점기로 오류를 만들어 채점하는 순환성을
완화한다. 민감도는 식 (2)로 정량화하며, 1에 가까울수록 지표가 오류를 잘 탐지함을 뜻한다.

$$\text{Sensitivity} = \frac{D(\hat{y}, r) - D(\tilde{y}, r)}{D(\hat{y}, r)} \quad (2)$$

여기서 $\tilde{y}$는 교란문이다. 본 지표는 조건 간 상대 비교를 위한 진단 도구이며, 방언성의 절대적
품질 척도는 아님을 명시한다.
