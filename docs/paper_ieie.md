## Ⅲ. 제안 방법

### 1. 시스템 개요

본 연구는 상용 API에 의존하지 않고 로컬 오픈소스 대규모 언어 모델(large language model, LLM)만을
이용하여 5개 권역(경상·전라·충청·강원·제주)의 방언 악취 민원 상담 대화를 합성하는 방법을 제안한다.
시스템의 입력은 악취 민원 시나리오를 구성하는 구조화된 키워드 슬롯, 즉 냄새 종류, 민원인 위치, 냄새
강도 변화, 지속 시간, 원인 추정 지역이며, 출력은 상담원과 민원인 사이의 8~10턴 상담 대화이다. 상담원
발화는 표준어로, 민원인 발화는 해당 권역의 방언으로 생성한다.

로컬 모델은 상용 모델에 비해 방언 내재 지식이 부족하여 방언 미적용이나 타권역 어미 혼입과 같은 품질
저하가 예상된다. 이를 보완하기 위해 웹 자원으로 구축한 방언 지식(어휘·문법 규칙)을 프롬프트에 주입할
수 있는지 검증하며, 지식 공급 방식을 독립변수로 하여 그 효과를 비교한다. 아울러 방언 화자에 의한 인간
평가가 어려운 상황을 전제로, 생성 결과의 방언성을 자동으로 진단하는 지표를 함께 설계한다.

### 2. 방언 지식베이스

방언 지식베이스는 검색·주입의 대상이 되는 두 종류의 자원으로 구성한다.

가. 어휘 자원

웹 사전을 수집하여 LLM으로 `{표준어, 방언형, 품사}` 형태로 구조화하였다. 5개 권역에 대해 각각 수천
에서 수만 개 규모의 표제어를 확보하였으며, 검색은 질의에 포함된 내용어를 표제어형으로 복원하여 정확
매칭으로 수행한다. 즉 질의에 등장한 명사·용언에 한하여 해당 방언형을 반환한다.

나. 문법 규칙 자원

문법서 및 웹에서 수집한 문법 정보를 `{표준형, 방언형, 설명}` 형태로 구조화하였다. 검색은 질의를
형태소 분석한 뒤 BM25로 관련 규칙을 순위화하여 상위 규칙을 반환한다. 다만 존댓말·종결·조사 어미와
같이 방언성 실현에 핵심적인 규칙은 질의와 무관하게 항상 주입하도록 설계하였다.

주입 시 검색된 지식은 다음과 같이 텍스트로 변환하여 프롬프트에 삽입한다.

```
[방언 어휘]
- '냄새' → 내굼새 / 내음새
[방언 문법 규칙]
- 표준형 → 방언형 (설명)
```

### 3. 생성 파이프라인

동일한 시나리오에 대해 두 가지 생성 전략을 비교한다.

가. 직접 생성 (S1)

키워드 슬롯으로부터 방언 대화를 한 단계로 직접 생성한다. 중간 표준어 텍스트가 없으므로 질의 기반
검색이 성립하기 어렵고, 방언 지식은 사실상 고정 주입에 가깝다.

나. 2단계 변환 (S2)

먼저 표준어 상담 대화를 생성한 뒤, 생성된 민원인 표준어 발화를 질의로 하여 방언 지식을 검색·주입하고
이를 방언으로 변환한다. 질의가 실제 문장이므로 어휘 검색의 적용 범위가 S1보다 넓다.

### 4. 지식 공급 조건

지식 공급 방식을 다음 네 가지 조건으로 구분하여, 방언 지식 주입 및 검색의 효과를 분리 측정한다(표 1).

**표 1.** 지식 공급 조건
Table 1. Knowledge injection conditions.

| 조건 | 공급 지식 | 분리 대상 |
|---|---|---|
| C0 | 없음(금지 규칙만) | 기준선 |
| C1 | 고정 few-shot 예시 | 예시 제공 효과 |
| C_kb | 방언 지식 검색·주입 | 검색 지식 효과 |
| C_kb+C1 | 검색 지식 + few-shot | 결합 효과 |

C1은 품질 향상이 검색에 의한 것인지 예시 제공에 의한 것인지 분리하기 위한 대조군으로 반드시 포함한다.
모든 조건에서 키워드, 프롬프트 구조, 출력 형식, 생성 파라미터, 검색 파라미터를 동일하게 고정하여 공정
비교를 보장한다.

### 5. 자동 진단 지표

인간 평가 없이 조건 간 방언성을 비교하기 위한 진단 지표를 설계한다.

가. 방언성 지표

방언 표지(marker)는 AI-Hub 방언 발화 코퍼스의 (표준어 종결어미, 방언 종결어미) 변환쌍에서 추출한다.
권역별 총빈도와 변별력을 기준으로 필터링하여 표지 목록을 구성한다. 권역 $r$의 생성문 $\hat{y}$에 대한
방언성 점수는 식 (1)과 같이 정의한다.

$$D(\hat{y}, r) = \frac{1}{|\hat{y}|}\left(\sum_{m \in M_r^{+}}\mathbb{1}[m \in \hat{y}] - \sum_{m \in M_r^{-}}\mathbb{1}[m \in \hat{y}]\right) \tag{1}$$

여기서 $M_r^{+}$는 권역 $r$의 방언 표지 집합, $M_r^{-}$는 타권역 표지 집합, $|\hat{y}|$는 어절 수이다.
구현에서는 이를 **방언율**(타깃 표지 적중 / 총어절)과 **누수율**(타권역 표지 적중 / 총어절)로 분리하여
보고한다. 방언율이 높을수록 해당 권역 방언을 잘 실현한 것이며, 누수율이 높을수록 타권역 어미가 혼입된
것이다.

나. 지표 신뢰성 검증

제안한 지표가 방언성을 타당하게 측정하는지를 인간 라벨 없이 검증하기 위하여, 정상 생성문에 통제된
오류를 주입한 교란문에 대한 지표의 반응을 측정한다. 교란은 채점기(표지 목록)와 독립인 참조 모델을
이용하여 두 가지 방식으로 수행한다. 첫째는 표준어화로, 방언을 표준어로 되돌렸을 때 방언율이 하락하는
정도(민감도)를 측정한다. 둘째는 타권역화로, 다른 권역 방언으로 변환하였을 때 원 권역 방언율이 하락하고
누수율이 상승하는 정도(특이도)를 측정한다. 교란기와 채점기가 독립이므로 순환성을 완화한다.

식 (2)의 민감도가 1에 가까울수록 지표가 방언 제거를 잘 탐지함을 의미한다.

$$\text{Sensitivity} = \frac{D(\hat{y}, r) - D(\tilde{y}, r)}{D(\hat{y}, r)} \tag{2}$$
