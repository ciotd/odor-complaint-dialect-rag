## 초록 (Abstract)

지자체 악취 민원은 전화 통화로 접수되며 실제 발화는 지역 방언과 구어체다. 이를 자동 처리하려면
방언 통화 데이터가 필요하나, 개인정보와 수집 비용 때문에 실제 방언 민원 데이터는 거의 없다.
본 연구는 **상용 API에 의존하지 않고 로컬 오픈소스 LLM(Qwen3.6-27B)** 만으로 5개 권역(경상·전라·
충청·강원·제주) 방언 악취 민원 대화를 합성하는 방법을 제안한다. 로컬 모델의 방언 지식 결핍을
보완하기 위해 웹 자원으로 구축한 방언 지식(어휘·문법 규칙)을 프롬프트에 주입하고, 지식 공급
방식(무주입 C0 / 고정 few-shot C1 / 지식 검색·주입 C_kb / 결합 C_kb+C1)을 독립변수로 비교한다.
직접 생성(S1)과 2단계 변환(S2) 두 파이프라인을 함께 분석한다. 인간 평가가 어려운 상황을 전제로,
AI-Hub 코퍼스에서 추출한 방언 종결어미 표지를 이용해 **방언율(dialectness rate)** 과 **타권역
누수율(leakage rate)** 을 자동 산출하는 진단 지표를 설계하고, 합성 교란 실험으로 지표의 민감도를
간단히 검증한다. 5권역 n=50 실험에서 직접 생성(S1)은 지식 주입에 따라 방언율이 단조 증가하고
(C_kb+C1이 방언율 최고·누수율 최저), 2단계 변환(S2)은 few-shot에만 강하게 반응하며 KB 검색
이득이 불안정하고 누수율이 높았다. 즉 표면 방언 품질과 낮은 누수 측면에서 직접 생성 + 결합
지식이 가장 효과적이었다. 다만 종결어미 중심 지표는 강원·제주처럼 어휘·음운 중심 방언을
과소평가하며, 로컬 모델은 한국어 전용 지시에도 40~50%의 대화에서 중국어·영어를 혼입하는 한계를
보였다.

## 1. 서론

- **문제 배경.** 악취 민원은 전화로 접수되고 실제 발화는 방언·구어체다. STT·키워드 추출로
  자동화하려면 방언 통화 데이터가 필요하지만, 실제 방언 악취 민원 데이터는 개인정보·수집 비용
  때문에 거의 존재하지 않는다. → 합성 데이터가 현실적 대안이다.
- **상용 API의 한계.** 상용 LLM(Claude, GPT)은 방언 지식이 풍부해 프롬프트만으로도 방언을 잘
  살리지만, 지속적 호출 비용, 민원 데이터의 외부 전송(프라이버시), 재현성 문제를 안는다.
- **로컬 LLM의 과제.** 로컬 오픈소스 모델은 방언 내재 지식이 약해, 방언 미적용·타권역 어미 혼입
  등 품질 저하가 예상된다. 본 연구는 **웹 자원 기반 방언 지식을 주입해 이 결핍을 보완**할 수
  있는지 검증한다.
- **평가의 문제.** 방언 화자 인간 평가는 비용·섭외가 어렵다. 인간 평가 부재 시에도 조건 간
  상대 비교가 가능한 **자동 진단 지표**가 필요하다.
- **기여 (Contributions).**
  1. 상용 API·파인튜닝 없이 로컬 LLM + 방언 지식 주입으로 5권역 방언 악취 민원 대화를 합성하는
     파이프라인(S1 직접생성 / S2 2단계 변환)과 지식 공급 조건 설계.
  2. 코퍼스 유래 방언 표지 기반의 reference-free 자동 진단 지표(방언율·누수율)와 합성 교란
     민감도 검증(A단계 간단 버전).
  3. 두 생성 전략(S1/S2)의 **품질–검색정당성 트레이드오프** 분석과 권역별 특성(강원·제주의
     구조적 한계 포함) 관찰.

## 3. 과제 및 데이터

### 3.1 과제 정의
- 도메인: 악취 민원 상담 통화. 상담원(표준어) ↔ 민원인(방언).
- 입력: 구조화된 키워드 슬롯 — 민원인 위치, 냄새 종류, 강도 변화, 지속 시간, 원인 추정 지역.
- 출력: 8~10턴 대화(첫·마지막 턴은 상담원). 첫 상담원 발화는 고정 인사 형식.
- 권역: 경상·전라·충청·강원·제주 (5권역). 단 제주는 KB 리소스 품질이 낮음(3.2).

### 3.2 방언 지식베이스 (KB)
- **어휘(vocab):** 웹 사전 스크래핑 → LLM으로 `{standard, dialect, pos}` 구조화. 검색은
  표제어 정확 매칭.
- **문법 규칙(rule):** 방언학 문법서·논문 기반 `standard_form → dialect_form` + 설명. 검색은
  형태소 기반 BM25.
- 5권역 중 4권역(경상·전라·충청·강원) 보유, **제주 KB는 정제·검수 미완**으로 커버리지가 낮다.
- 라이선스: 원자료(단어 목록)는 비공개, 방법·스크립트만 공개해 재현성 확보.

### 3.3 평가용 방언 표지 추출
- AI-Hub 2인 발화 코퍼스에서 (표준 종결어미 → 방언 종결어미) 변환쌍을 추출.
- 필터: 총빈도 ≥ 8, 권역 변별력(주권역 집중). 자동 추출로 65개 확보.
- 자동 추출이 놓친 핵심 존댓말 종결형은 수동 보완: 충청 유/슈, 강원 믄, 경상 예,
  전라 당께(요)/랑께(요)/여라/겄소/부러. (수동 개입은 한계로 명시 — 8절)

## 4. 생성 방법

### 4.1 두 생성 전략
- **S1 (직접 생성):** 키워드 슬롯 → 조건별 지식 주입 → 방언 대화 직접 생성. 쿼리(중간 표준어
  텍스트)가 없으므로 엄밀히는 **권역 지식 주입(injection)** 이며 질의 기반 검색은 아니다.
- **S2 (2단계 변환):** 키워드 → 표준어 대화 생성 → (표준어 민원인 발화를 쿼리로) 어휘·규칙
  검색·주입 → 방언 변환. 쿼리가 있으므로 **질의 기반 검색(retrieval)** 이 성립한다.
- 두 전략은 상호 배타가 아니라 서로 다른 질문에 답한다(6절 트레이드오프 분석).

### 4.2 지식 공급 조건 (독립변수)

| 조건 | 주입 내용 | 분리하는 것 |
|---|---|---|
| C0 | 없음 (금지규칙만) | 기준선 (진짜 zero-shot) |
| C1 | 고정 few-shot 예시 (질의 무관) | "예시가 있어서" 생기는 효과 |
| C_kb | KB 어휘+규칙 검색·주입 | 지식 검색의 효과 |
| C_kb+C1 | KB + few-shot 결합 | 두 지식원의 결합 효과 |

- C1을 반드시 포함하는 이유: 품질 향상이 "검색 때문"인지 "예시가 있어서"인지 분리하는 유일한
  대조군.
- 공정 비교를 위해 동일 키워드·프롬프트 구조·출력 형식·temperature·max_tokens·검색 파라미터를
  고정한다.

### 4.3 프롬프트 설계
- 한국어 전용 강제(한자·중국어·일본어·영어 금지), 민원인 존댓말 유지, 상담원 표준어 유지.
- 타권역 어미 누수 금지 목록과 혼종어미 금지 목록을 명시.
- 발화자 라벨 형식("상담원:/민원인:")을 강제 — 라벨 누락 시 자동 채점이 불가하기 때문.

## 5. 자동 진단 지표

### 5.1 방언율과 누수율 (B단계)
권역 $r$의 생성문 $\hat{y}$에 대해:

$$D(\hat{y}, r) = \frac{1}{|\hat{y}|}\Big(\sum_{m \in M_r^+}\mathbb{1}[m \in \hat{y}]
- \sum_{m \in M_r^-}\mathbb{1}[m \in \hat{y}]\Big)$$

- $M_r^+$: 권역 $r$의 방언 표지(+), $M_r^-$: 타권역 표지(−), $|\hat{y}|$: 어절 수.
- **방언율** = 타깃 표지 적중 / 총어절, **누수율** = 타권역 표지 적중 / 총어절.
- S1: 민원인 발화 어절의 표면 접미 매칭. S2: 표준↔방언 정렬 어절쌍(difflib) 기반 매칭.
- 오탐 방지: 1자 표지는 화이트리스트 + 앞 음절 무받침 조건(예: "윤활유"의 '유' 차단),
  표준어 동형 표지("어서","가지고") 제외.

### 5.2 지표 신뢰성 — 합성 교란 (A단계, 간단 버전)
- 정상 생성문에 알려진 오류를 통제 주입한 교란문 $\tilde{y}$을 만든다.
  - (i) 타권역 어미로 교체, (ii) 방언형을 표준어로 역치환(방언 미변환).
- B 지표가 교란을 얼마나 잡는지 민감도로 측정:
  $$\text{Sensitivity} = \frac{D(\hat{y}, r) - D(\tilde{y}, r)}{D(\hat{y}, r)}$$
- 목적: 인간 라벨 없이 지표가 "정상 vs 오염"을 구분하는지 실증. 본격 민감도/특이도 분석은
  future work.
- **포지셔닝:** 본 지표는 조건 간 상대 비교용 진단 도구이며 절대적 방언 품질 척도가 아니다.

### 6.2 방언율·누수율 결과 (n=50)

**표 1. S1(직접 생성) 권역×조건 — 방언율 / 누수율.** (권역당 n=10)

| 권역 | C0 | C1 | C_kb | C_kb+C1 |
|---|---|---|---|---|
| 경상 | 0.006 / 0.001 | 0.081 / 0.001 | 0.017 / 0.005 | **0.081** / 0.002 |
| 전라 | 0.000 / 0.020 | 0.055 / 0.000 | 0.026 / 0.006 | **0.055** / 0.005 |
| 충청 | 0.005 / 0.000 | 0.079 / 0.002 | 0.052 / 0.000 | **0.099** / 0.001 |
| 제주 | 0.006 / 0.037 | **0.042** / 0.004 | 0.006 / 0.016 | 0.040 / 0.004 |
| 강원 | 0.000 / 0.006 | 0.000 / 0.007 | 0.000 / 0.008 | 0.000 / 0.003 |
| **전체** | 0.003 / 0.013 | 0.052 / 0.003 | 0.021 / 0.007 | **0.057 / 0.003** |

- 강원을 제외한 4권역 모두 지식 주입에 따라 방언율이 상승하고, C_kb+C1이 방언율 최고·누수율
  최저(전체 방언율 0.057, 누수율 0.003)다. C0는 사실상 방언을 생성하지 못한다(0.003).
- 전체 랭킹: **C_kb+C1 > C1 > C_kb > C0** (방언율 기준, 단조).

**표 2. S2(2단계 변환) 권역×조건 — 방언율 / 누수율.** (권역당 n=10)

| 권역 | C0 | C1 | C_kb | C_kb+C1 |
|---|---|---|---|---|
| 경상 | 0.036 / 0.096 | 0.173 / 0.039 | 0.065 / 0.013 | **0.174** / 0.000 |
| 전라 | **0.138** / 0.035 | 0.123 / 0.029 | 0.055 / 0.007 | 0.025 / 0.011 |
| 충청 | 0.137 / 0.016 | **0.291** / 0.015 | 0.150 / 0.021 | 0.160 / 0.017 |
| 제주 | 0.010 / 0.080 | **0.026** / 0.029 | 0.016 / 0.089 | 0.018 / 0.029 |
| 강원 | 0.033 / 0.008 | **0.191** / 0.016 | 0.005 / 0.015 | 0.091 / 0.000 |
| **전체** | 0.062 / 0.049 | **0.127 / 0.027** | 0.055 / 0.031 | 0.077 / 0.013 |

- S2에서는 **few-shot(C1)이 가장 강한 지렛대**이고, KB 검색(C_kb)은 C0보다도 낮아(전체
  0.055 < 0.062) 신뢰성 있는 개선을 주지 못한다. 전라에서는 C0(0.138) > C_kb(0.055)로 역전된다.
- 전체 랭킹: **C1 > C_kb+C1 > C0 > C_kb**. S1과 달리 단조가 아니다.

> **주의(분모 차이):** S1 방언율의 분모는 민원인 발화 전체 어절, S2는 표준↔방언 정렬에서 실제로
> 치환된 어절쌍이다. 따라서 S1과 S2의 방언율 **절대값은 직접 비교할 수 없고**, 각 파이프라인
> **내부의 조건 순서**와 **누수율**로만 해석한다.

### 6.3 S1 vs S2 트레이드오프
- **품질·안정성:** S1은 지식 주입 효과가 단조적이며 누수율이 낮다(전체 C_kb+C1 누수 0.003).
  S2는 few-shot에만 강하게 반응하고 KB 검색 효과가 불안정하며 누수율이 전반적으로 높다
  (전체 C0 누수 S2 0.049 vs S1 0.013).
- **검색 정당성:** 반대로 S2만이 쿼리(중간 표준어 텍스트) 기반의 실제 검색을 성립시킨다. S1의
  C_kb는 쿼리가 없어 권역 지식 통째 주입에 그친다.
- **결론적 함의:** 표면 방언 품질과 낮은 누수가 목표라면 **직접 생성(S1) + 결합 지식(C_kb+C1)**
  이 가장 효과적이다. 2단계 변환은 검색을 성립시키는 대신 누수·불안정성 비용을 치르며, 본
  실험 범위에서 KB 검색이 few-shot을 넘어서는 이득을 보이지 못했다.

### 6.4 권역별 분석
- **강원:** S1에서 전 조건 방언율 = 0. 강원 방언은 종결어미 변화보다 어휘·음운 변화(아이들→아들,
  같아→같애)가 특징이라 어미 표지 기반 지표로 포착되지 않음 — 지표의 구조적 한계이지 생성
  실패가 아님. (S2에서는 정렬쌍 매칭이 일부 어미 변환(예: -아요→-소)을 잡아 C1 0.191로 측정됨.)
- **제주:** KB가 부실해 C_kb 효과가 미미하다(S1 C_kb 0.006 ≈ C0). C1·C_kb+C1에서만 방언율을
  확보(S1 0.04대). KB 없이 few-shot이 제주 방언을 이끄는 셈.
- **경상·충청:** 지식 주입 효과가 가장 뚜렷. 충청 S1 C_kb+C1 방언율 0.099로 최고.

**정성 예시.** 실제 생성 대화 발췌(민원인 발화)로 정량 결과를 뒷받침한다.

- (성공, S1 충청 C_kb+C1) "세종에서 전화 **혀는디유**. 대창빌라 맞은편에 사는데 유난히 고약한
  냄새가 나서 전화**혔슈**." → 충청 존댓말 방언형(-는디유/-혔슈)이 자연스럽게 실현됨.
- (성공, S1 경상 C_kb+C1) "접착제 냄새 나는 **기라예**. 코가 슬슬 따가워질 지경**입니더**." →
  경상 종결형(-기라예/-입니더) 실현.
- (지표 한계, S1 강원 C_kb+C1) "전화**했잖소**. … 거름 냄새**래요**. … 있**잖우야**. 코가 다
  **따갑소**." → 강원 방언형(-잖소/-래요/-우야/-소)이 뚜렷하나 방언율 지표는 0으로 측정됨.
  이는 해당 표지가 1자(-소)이거나 표지 목록 미포함이기 때문으로, **생성 실패가 아니라 지표의
  구조적 한계**임을 보여준다.
- (타권역 누수, S2 경상 C0) "접착제 냄새가 **나가유**. … 언제부터인지 기억이 안 **나유**." →
  경상 대화에 충청 종결형(-유)이 혼입. 지식 주입 없는 2단계 변환에서 누수가 두드러진다.

### 6.5 지표 민감도 검증 (A단계)
정상 생성문(S1 C_kb+C1)의 타깃권역 방언 어미(+적중)에 통제된 오류를 주입해 B 지표의 반응을
측정했다(방언이 실현된 대화 39개 대상).

| 권역 | D(정상) | D(표준화) | D(타권역치환) | 누수(정상) | 누수(타권역치환) |
|---|---|---|---|---|---|
| 경상 | 0.081 | 0.000 | 0.000 | 0.002 | 0.082 |
| 전라 | 0.055 | 0.000 | 0.000 | 0.005 | 0.061 |
| 제주 | 0.045 | 0.000 | 0.000 | 0.004 | 0.049 |
| 충청 | 0.099 | 0.002 | 0.000 | 0.001 | 0.101 |

- **표준어 역치환 민감도 0.995**, **타권역 교체 민감도 1.000**: 방언 어미를 표준형/타권역형으로
  바꾸면 방언율이 거의 완전히 소거된다.
- **타권역 교체 시 누수율 +0.071 상승**: 주입한 타권역 어미가 실제로 누수로 검출된다.
- **해석과 한계:** 역치환 민감도가 1에 가까운 것은 채점과 동일한 표지 매처로 오류를 주입하므로
  부분적으로 구성상 자명하다. 더 의미 있는 신호는 타권역 어미가 독립적으로 누수로 인식된다는
  점이다. 따라서 본 검증은 "인간 판단 대비 타당성 검증"이 아니라 **통제된 오염에 지표가 올바른
  방향으로 단조 반응하는지의 일관성 검사**로 해석한다(본격 민감도/특이도는 future work).

### 6.6 부수 관찰: 외국어 혼입 (로컬 모델 한계)
- 한국어 전용 지시에도 불구하고 생성문에 중국어·영어 잔재가 관찰됨: 예) 开窗(개창), 这边/那边
  (여기/저기), 腥(비린), 风向(풍향), "yeah".
- **혼입 대화 비율(한자 또는 라틴문자 1자 이상 포함):** S1 40~52%(C0 46%, C1 40%, C_kb 52%,
  C_kb+C1 40%), S2 24~32%. 지식 주입으로도 완전히 억제되지 않으며, S1이 S2보다 높다.
- 이는 로컬 오픈소스 모델(Qwen)의 다국어 사전학습에서 비롯된 code-switching 경향으로, 상용
  API 대비 로컬 접근의 실질적 약점이다(후처리 필터 필요).

## 7. 논의
- **지식 주입은 유효하나 그 양상이 파이프라인에 따라 다르다.** S1에서는 KB·few-shot·결합이 모두
  방언율을 높이며 결합(C_kb+C1)이 최고다. S2에서는 few-shot이 지배적이고 KB 검색 단독은 개선을
  보장하지 못했다.
- **few-shot이 KB 검색보다 안정적이다.** 두 파이프라인 모두에서 C1의 효과가 크고 일관적이다.
  이는 로컬 모델에 방언을 유도할 때, 검색된 어휘·규칙 조각보다 완결된 대화 예시가 더 강한
  신호임을 시사한다. KB 검색의 이득은 주로 few-shot과 결합될 때(S1 C_kb+C1) 드러난다.
- **파이프라인 선택.** 표면 방언 품질과 낮은 누수가 목표라면 직접 생성(S1)이 우세하다. 2단계
  변환(S2)은 쿼리 기반 검색을 성립시키는 이론적 장점이 있으나, 본 실험에서는 누수 증가와 검색
  이득 불안정이라는 실질 비용이 더 컸다.
- **로컬 모델의 한계.** 방언율과 별개로, 40~50%의 대화에 외국어가 혼입되어 후처리 필터가
  필수적이다. 이는 상용 API 대비 로컬 접근이 감수해야 할 비용이다.

## 8. 한계
- 지표가 종결어미에 편향 → 강원·제주 등 어휘·음운 중심 방언을 과소평가.
- 표지 목록에 수동 보완·오탐 규칙이 포함 → 완전 자동·객관은 아님.
- 인간 평가 부재 → 지표의 절대 타당성 미검증(상대 비교로만 사용).
- 단일 모델·단일 도메인, 표본 규모 제한.
- RQ2(어휘 vs 규칙 기여 분해)는 본 논문 범위에서 제외(future work).

## 9. 결론
상용 API 없이 로컬 오픈소스 LLM과 방언 지식 주입만으로 5권역 방언 악취 민원 대화를 합성하고,
인간 평가 없이 조건을 비교하는 자동 진단 지표를 제시했다. 지식 주입이 방언성을 높이고 누수를
줄임을 확인했으며, 직접 생성과 2단계 변환의 트레이드오프를 분석했다.
