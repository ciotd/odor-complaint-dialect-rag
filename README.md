# 경상도 방언 지식그래프 연구

이 저장소의 현재 연구는 **표준어 문장을 자연스러운 경상도 방언 문장으로 변환하기 위한
지식그래프(KG)를 처음부터 재구축하는 것**이다.

과거 v1 연구와 실패한 v2 실험은 재현·감사 목적으로 `archive/`에 보존하며, 현재 KG의
근거나 구현으로 사용하지 않는다.

## 먼저 읽을 문서

1. `current_kg/docs/RESET_2026-08-31.md` — 이전 실험이 왜 측정 실패인지 설명하는 정본
2. `current_kg/docs/SOURCE_REVIEW_2026-09-07.md` — 현재 사용할 자료와 추출 원칙
3. `PROJECT_MAP.md` — 현재 디렉터리와 문서 권한

## 디렉터리

```text
current_kg/                 현재 KG 재구축 작업
sources/                    현재 연구가 읽을 원문·방법론 자료
archive/v1_retrieval/       기존 5권역 악취 RAG 연구
archive/v2_failed/          실패한 종결어미 39규칙 기반 v2
```

## 현재 단계

- 활성 문헌 3종의 1차 자료 검토 완료
- 경상 어휘 JSON은 별도 어휘 후보 자료로 보류
- 기존 종결어미 39규칙은 완전 제외
- AI-Hub 표준어-방언 코퍼스는 Claim 근거에서 제외하고 독립 평가 후보로 보존
- Claim 자료 통제표·기록 스키마·추출 원칙 초안 작성 완료
- 다음 작업은 세 문헌에서 각 5~10건의 파일럿 Claim을 새로 추출하는 것
- Claim 검토가 끝나기 전에는 KG 노드·관계나 운영 Rule을 확정하지 않음
