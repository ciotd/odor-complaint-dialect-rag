# 경상도 방언 지식그래프 연구

## 현재 상태 — 2026-10-12

연구 질문은 **경상도 방언 문법 지식을 체계적으로 구성하고 입력 문장에 필요한 지식을 제공하면, 로컬 LLM이 의미를 유지하면서 더 자연스러운 경상도 방언을 생성할 수 있는가?**이다. KG는 이를 검증하기 위한 방법 가설이지, 이미 우월성이 입증된 해결책이 아니다.

현재 작업은 기존 `current_kg`를 보존한 별도 **[KG v2](kg_v2/README.md)**다. 직접 근거 문헌 7종·474쪽을 대상으로 Astra가 초안을 작성했고, 10월 12일 사용자 승인에 따라 Astra 작업자 3개가 남은 추출·검토 항목을 병렬 보완했다. 통합 결과와 검증 범위는 KG v2 안내 및 보고서를 따른다. 전체 페이지 독해, 지식 추출, 근거 검토, 문장 번역 검증은 각각 다른 단계다.

기존 KG의 30문장×4조건 실험은 [비교 원문](current_kg/experiments/reports/integrated_development/comparison.txt)에 보존했다. 이 결과에서 KG의 번역 품질 개선은 입증되지 않았고, 새 표현 구조를 검토하는 계기가 됐다. 이 실험을 KG v2의 평가 결과로 취급하지 않는다.

KG를 선택한 출발점은 **경상도 방언 문법 체계를 형태·기능·결합 관계의 그래프로 표현하고 이를 활용한 자연스러운 생성을 시도하는 것**이다. 검색 개선 자체가 주목적은 아니다. 지역·시대는 근거 범위를 보존하는 보조 정보이며 세부 지역 분류·지역별 생성이 중심 과제는 아니다.

## 어디부터 읽을까?

**새 지식 구조와 검토 결과는 [kg_v2/README.md](kg_v2/README.md), 이전 KG와 생성 실험은 [current_kg/README.md](current_kg/README.md)에서 본다.**

- [이관.md](이관.md): 새 세션 필독. 사용자 판단 원칙·최종 목적·논문 기록 원칙, 실제 상태와 재개 절차.
- [연구미팅.md](연구미팅.md): 연구 목적·합의·미정 사항·현재 상태·전체 계획을 담은 의사결정 요약.
- [현재 작업과 파일 설명](current_kg/README.md): 실제 산출물, 처리 범위, 다음 단계.

- [선행연구 11편 검토](sources/methodology/선행연구.md): 서론 근거·관련 연구·실험 설계 아이디어.
- [프로젝트 지도](PROJECT_MAP.md): 현재 작업과 과거 이력 구분.
- [서론 작업 초안](paper/INTRODUCTION_DRAFT.md): 미검증 인용·수치가 남은 작업본이며 확정 원고가 아니다.

## 실제 완료 범위

- 기존 KG: 334기록. 기존 구조·산출물은 보존하며 이번 보완에서 재작성하지 않았다.
- 새 KG: 문헌 7종·474쪽 전체 검토를 거친 별도 초안. 최신 진술·그래프 규모와 해시는 [빌드 결과](kg_v2/reports/build_summary.json)에 있다.
- 병렬 보완: 원래 공백을 기록한 162쪽을 세 작업자에게 나눠 검토했다. 해결·일부 해결·원문 한계를 구별하며 [통합 감사](kg_v2/reports/integration_audit.json)에서 확인한다.
- 입력 기본형→방언 어휘→문헌의 활용형 경로를 구현했다. 예: 먹다 + -고 → 묵다 → 묵고. 입력 분석값을 직접 제공한 조회 검사이며 문장 번역 성공을 뜻하지 않는다.
- 기존 문법 구현 테스트 98개, 실험 코드 테스트 77개가 통과했다. KG v2 검사는 [검증 결과](kg_v2/reports/verification.json)를 따른다. 구현 검사·모델의 원문 검토를 독립적인 언어학 검증으로 포장하지 않는다.
- 문헌 밖의 정보, 문헌 자체의 모순·불명확한 전사, 미확보 외부 자료는 추정으로 채우지 않는다. 새 KG의 문장 분석 연결·통제된 생성 비교와 사람 평가는 남아 있다.

## 유지할 경계

문법 작성은 Codex/Astra가 원문을 직접 검토해 수행하고, Qwen은 생성 실험용으로 둔다. 모델 명칭 `Qwen3.8-27B`는 사용자 지정 및 과거 배포 응답 명칭이며 정확한 체크포인트·양자화는 실험 전에 기록한다. 로컬 모델이 상용 모델보다 반드시 열등하다고 전제하지 않는다.

AI-Hub는 문법 근거가 아닌 독립 평가 후보, 어휘 JSON은 별도 후보로 유지한다. PDF·AI-Hub 파생 문장쌍·어휘 원본·인증정보는 Git에 올리지 않는다.

현재 KG의 이전 Claim 구현·산출물은 정리했으며 현행 지식과 합산하지 않는다. v1/v2의 코드·문서·실험 이력은 archive/에 보존하고 논문의 연구 동기·시행착오·오류 분석에 활용한다. 과거 실험을 새 KG의 통제 비교 결과로 취급하지 않는다. 이전 부산 24문장 실험안도 현행 계획이 아니다. 자동 검토 workflow는 구축하지 않았으며, 새 독립 연구 검토자의 역할·검토 절차는 아직 설계 단계다.
