# 경상도 방언 지식그래프 연구

## 현재 상태 — 2026-09-15

연구 질문은 **경상도 방언 문법 지식을 체계적으로 구성하고 입력 문장에 필요한 지식을 제공하면, 로컬 LLM이 의미를 유지하면서 더 자연스러운 경상도 방언을 생성할 수 있는가?**이다. KG는 이를 검증하기 위한 방법 가설이지, 이미 우월성이 입증된 해결책이 아니다.

현재는 공통 문법 체계의 부분 작성과 선행연구 검토를 마치고 **KG의 기여 / 지식 품질 기준 / 공정한 비교 실험**을 논의하는 단계다. 세부 설계는 아직 합의 전이다. 현대 부산이나 전통 방언만으로 목표를 고정하지 않는다.

## 실제 완료 범위

- 새 문법 지식: `current_kg/grammar/records.jsonl`의 **67건**. 문법 PDF 65건, 높임법 PDF 2건이며 나머지 4문헌은 새 규격 작성 0건이다.
- 새 그래프: `current_kg/grammar/grammar.graph.json`의 **2,121노드·5,478엣지**. 이 수치는 출처·조건·예문 관계도 포함하며 문법 정확성 지표가 아니다.
- 작성자 원문 대조 표시 55건, 독립 검토·생성 사용 승인 0건. 설명용 예문은 독립 근거나 평가 정답이 아니다.
- 원문 6종·452쪽의 새 체계 구축, 입력 분석기·실행 조건 판정기·조합 판정·새 KG 기반 생성 비교는 미완료다.
- 방법론 논문 11편을 검토했다. 실험 재현·분야 전체의 체계적 문헌조사 완료를 뜻하지 않는다.
- AI-Hub 100문장 예비 진단을 제안했고 로컬 후보 파일과 구성 스크립트가 있다. 문장 경계·화자·선별 편향 점검과 실제 생성·평가 결과는 별도로 확인해야 한다.

## 유지할 경계

문법 작성은 Codex/Astra가 원문을 직접 검토해 수행하고, Qwen은 생성 실험용으로 둔다. 모델 명칭 `Qwen3.8-27B`는 사용자 지정 및 과거 배포 응답 명칭이며 정확한 체크포인트·양자화는 실험 전에 기록한다. 로컬 모델이 상용 모델보다 반드시 열등하다고 전제하지 않는다.

AI-Hub는 문법 근거가 아닌 독립 평가 후보, 어휘 JSON은 별도 후보로 유지한다. PDF·AI-Hub 파생 문장쌍·어휘 원본·인증정보는 Git에 올리지 않는다.

기존 `current_kg/claims/v3/`의 688 Claim 그래프, 류성기 318건, v1/v2는 **이력**이며 새 문법 지식의 입력이나 성과로 합산하지 않는다. 이전 부산 24문장 실험안도 현행 계획이 아니다. 자동 검토 workflow는 구축하지 않았으며, 새 독립 연구 검토자의 역할·검토 절차는 아직 설계 단계다.
