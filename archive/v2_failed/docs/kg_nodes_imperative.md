# 경북 방언 KG 노드 — 명령법 (종결법=명령)

출처: 조현준(2018) §3.1.3(격식)·§3.2.3(비격식), 표29~36·53. 추출 2026-08-25. 스키마 `kg_schema.md`.
명령법은 판정/설명 없음. 조건 = {명령, 높임}. 검증상태 전부 ①추출-미검증.

## 격식체
```
(R_명령_하이소) {명령, 하이소체}  방언: -이소, -시소        표준: -시오(쇼)/-ㅂ시오
   속성: -이소~-시소 (-이- 결합=하이소체 표지). 표28 p149.
(R_명령_하소)   {명령, 하소체}    방언: -소  (방언형만)
   속성: -소 어간 직접결합(서술의 -소는 선어말어미 뒤). 표31 p156.
(R_명령_하게)   {명령, 하게체}    방언: -세이         표준: -게, -세, -구려
   표33 p159.
(R_명령_해라)   {명령, 해라체}    방언: -래, -래이, -가래이/-거래이, -나래이/-느래이, -가/고, -ㄴ나
                                 표준: -라, -거라, -나라/-너라/-니라
   속성: -가/고는 의문 -가/고와 형태 겹침(문맥·억양 구분). 표35 p164.
```

## 비격식체
```
(R_명령_해)    {명령, 해체}   -아/어  (특별 형태 없음; -제는 문맥의존, ④불확실)  §3.2.3.1 p217
(R_명령_해요)  {명령, 해요체} -요, -시요, -세요, -ㅂ시요, -지요
(R_명령_해예)  {명령, 해예체} -지예
(R_명령_해여)  {명령, 해여체} -여          (예형 거의 없음)   표53 p219
```

## 메모
- 명령법 방언형은 등급별로 적음(하소체는 -소 하나). 조건부 분기 약함 → KG 이득 제한적(의문법 대비).
- -가/고(해라 명령) ↔ -가/고(해라 의문) 동형 → 생성 시 문맥/억양 의존, 주의.
