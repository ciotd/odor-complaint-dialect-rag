# 프롬프트·조건·RAG 검색 실제 예시 (참고 문서)

목적: 각 조건(C0/C1/C_kb/C_kb+C1)에서 **실제로 프롬프트에 무엇이 들어가는지**, C1 권역별 예시가
무엇인지, C_kb의 RAG **검색 쿼리와 결과**가 어떤 모습인지를 실물로 보여준다. 코드 근거:
`prompts/prompt_template.txt`, `data/c1_examples.json`, `data/regional_dialogue_examples.json`,
`src/retrieval/kb_retriever.py`, `src/generation/s1_pipeline.py`.

---

## 1. 공통 생성 프롬프트 (뼈대)

모든 조건은 동일한 `prompt_template.txt`를 쓰고, 그 안의 `{knowledge_block}` 자리에만 조건별
지식이 삽입된다. 뼈대의 핵심:
- 입력 슬롯: region_name, complainant_location_text, smell_type, smell_intensity, smell_duration,
  suspected_location_text
- 규칙: 상담원=표준어, 민원인=권역 방언 **존댓말**, 8~10턴, 첫·끝 턴은 상담원, **한국어만**(외국어 금지)
- 금지: 혼종 어미(예: 경상 ~카이), **타권역 어미 누수**(권역별 금지 목록 명시)
- 출력: "상담원: …" / "민원인: …" 대화만

즉 조건 간 차이는 **오직 `{knowledge_block}`** 이다. (공정 비교의 핵심)

---

## 2. 조건별 knowledge_block (실제 삽입 내용)

### C0 — 지식 없음
```
{knowledge_block} = ""   (빈 문자열)
```
금지 규칙(뼈대)만 있고 추가 지식 없음 = zero-shot 기준선.

### C1 — 고정 few-shot 예시
권역 대화 예시(약 550~730자) + 표준어/방언 쌍(권역당 6~7개)이 삽입된다.
```
[방언 대화 예시 — 아래 대화를 참고해 해당 권역의 자연스러운 방언을 사용한다]
(권역 상담 대화 1편)

[방언 표현 참고 — 아래 표준어/방언 쌍을 참고한다]
표준어: 여기 근처에서 심한 악취가 나서 신고하려고 합니다.
방언:   여어 근처에서 억수로 냄새가 나가 신고하려고예.
...
```

### C_kb — RAG 검색·주입
검색된 어휘 + 문법 규칙(+예문)이 삽입된다(§4 실제 예시 참조).
```
[활용할 방언 지식 — 우선 참고하되, 없는 표현은 자연스러운 방언으로]
[방언 어휘]
- '냄새' → 냄섀
[방언 문법 규칙]
- 해요체 -어요 → -어예 (...) [예: 좋아요→좋아예]
...
```

### C_kb+C1 — 결합
C_kb 블록 + C1(권역 대화 예시 + 표준어/방언 쌍)을 모두 삽입.

---

## 3. C1 권역별 표준어/방언 쌍 (전체)

개수: **경상 6 · 전라 7 · 충청 7 · 강원 7 · 제주 7쌍.** (`data/c1_examples.json`)

**경상 (6)**
- 여기 근처에서 심한 악취가 나서 신고하려고 합니다. → 여어 근처에서 억수로 냄새가 나가 신고하려고예.
- 며칠째 계속 냄새가 나는데 도저히 참을 수가 없어요. → 며칠째 계속 냄새가 나가 도저히 몬 참겠어예.
- 이게 무슨 냄새인지 알아봐 주실 수 있습니까? → 이기 무슨 냄새인지 알아봐 주실 수 있능교?
- 밤만 되면 하수구에서 고약한 냄새가 올라옵니다. → 밤만 되마 하수구에서 고약한 냄새가 올라오는 기라예.
- 창문을 열 수가 없을 정도로 냄새가 지독해요. → 창문을 몬 열 정도로 냄새가 지독하데이.
- 아까 담당자한테 전화했는데 아직도 연락이 안 옵니다. → 아까 담당자한테 전화했는데 아직도 연락이 안 옵니더.

**전라 (7)**
- 여기 냄새가 너무 심해서 도저히 못 살겠어요. → 여그 냄새가 너무 심해갖고 도저히 못 살겄소.
- 밤마다 공장에서 이상한 냄새가 나니까 좀 조사해 주세요. → 밤마다 공장에서 요상한 냄새가 나부러갖고 쪼까 조사해 주쑈.
- 창문을 열 수가 없을 정도로 악취가 진동해요. → 창문을 열 수가 없을 정도로 악취가 진동한당께요.
- 아침부터 계속 이런 냄새가 나서 머리가 다 아파요. → 아침부텀 계속 이런 냄새가 나갖고 머리가 다 아프구만요.
- 축사에서 냄새가 넘어오니까 빨리 좀 와 주셨으면 좋겠어요. → 축사에서 냄새가 넘어옹께 쪼까 와 주씨면 좋겄소.
- 이 냄새 때문에 온 동네 사람들이 다 힘들어해요. → 이 냄새 땀시 온 동네 사람들이 다 심들어한랑께요.
- 하수구에서 썩은 냄새가 올라와서 속이 다 메스꺼워요. → 하수구에서 썩은 냄새가 올라와부러갖고 속이 다 미식거리당께요, 잉.

**충청 (7)**
- 여기 축사에서 냄새가 너무 심하게 나요. → 여기 축사에서 냄새가 너무 심하게 나유.
- 밤마다 이 악취 때문에 잠을 못 자겠어요. → 밤마다 이 악취 땜시 잠을 못 자겄슈.
- 도대체 이 냄새가 어디서 나는 건가요? → 도대체 이 냄새가 워디서 나는 겨요?
- 아까 공장 쪽에서 이상한 냄새가 올라왔어요. → 아까 공장 쪽에서 이상한 냄새가 올라왔어유.
- 이거 언제쯤 조치해 주실 수 있나요? → 이거 언제쯤 조치해 주실 수 있남유?
- 창문을 못 열 정도로 지독한데 어떡하죠? → 창문을 못 열 정도로 지독헌디 워쩐대유?
- 담당자분이 한번 나와 봐 주셔야겠어요. → 담당자분이 한번 나와 봐 주셔야 쓰겄슈.

**강원 (7)**
- 여기 냄새가 너무 심해서 신고합니다. → 여기 냄새가 너무 심해서 신고하래요.
- 어디서 이런 악취가 나는지 좀 알아봐 주세요. → 어디서 이런 악취가 나는지 좀 알아봐 주소.
- 밤새 냄새 때문에 창문도 못 열었습니다. → 밤새 냄새 땜에 창문도 못 열었소.
- 이 정도면 담당자가 직접 나와 봐야겠습니다. → 이 정도면 담당자가 직접 나와 봐야겠소.
- 저 공장에서 나는 냄새가 확실합니다. → 저 공장에서 나는 냄새가 확실하래요.
- 빨리 조치 좀 취해 주세요. → 빨리 조치 좀 취해 주소.
- 이러다 사람이 못 살겠습니다. → 이러다 사람이 못 살겠소.

**제주 (7)**
- 여기 냄새가 너무 심해서 신고하려고 전화했어요. → 여기 냄새가 하영 심해부난 신고허젠 전화헷마씸.
- 밤마다 이상한 악취가 나서 창문을 못 열어요. → 밤마다 이상한 악취가 남시난 창문을 못 열엄수다.
- 이 근처에 축사가 있어서 그런 것 같아요. → 이 근처에 축사가 이셩 경헌 거 닮수다.
- 담당자분이 한번 나와서 확인해 주세요. → 담당자분이 혼번 나왕 확인해 줍서.
- 아이들이 냄새 때문에 밖에 나가질 못하네요. → 아이덜이 냄새 때문에 밲에 나가지 못햄수다게.
- 며칠째 계속 이런 냄새가 나고 있어요. → 메칠째 계속 이런 냄새가 나마씀.
- 빨리 조치를 취해 주셨으면 좋겠어요. → 빨랑 조치를 취해 주민 좋키어마씨.

### 참고 — C1 권역 대화 예시(경상, 발췌)
```
상담원: 안녕하세요. 경주시 기후대기과 악취 대응팀입니다. 어떤 도움을 드릴까요?
민원인: 아이고, 여기 냄새 때문에 전화했심더. 좀 봐주소. 계속 이상한 냄새가 나가 미치겠어예.
상담원: 불편을 드려 죄송합니다. 어떤 냄새인지 조금 더 구체적으로 말씀해 주시겠어요?
민원인: 뭐라캐야 되노, 꼭 김치 국물 쉰 냄새 같은 기라예. ...
```
(권역당 1편, 약 550~730자)

## 4. C_kb RAG 검색 실제 예시 (쿼리 → 결과)

검색 방식: **어휘 = 표제어 정확매칭**(질의 내용어 → 사전 방언형), **문법 = 범주 고정주입 + BM25**.
실행: `python src/retrieval/kb_retriever.py --region <권역> "<질의>"`

### 예시 A — 경상, S1식 질의(키워드) vs S2식 질의(문장)

**S1식 질의 = `"음식물 쓰레기 시장"` (키워드만):**
```
[방언 문법 규칙]          ← 어휘 0개. 규칙은 전부 고정주입 어미
- 해요체 -어요, -이어요 → -어예, -이라예 (...)
- 하십시오체 -습니다 → -(스)ㅂ니더 (...)
- 하소체 -소, -나요 → -소, -는교, -는기요 (...)
  ...(고정 어미 11개)
```
→ 질의에 내용어(냄새 등)가 없어 **어휘 검색 0**, 문법은 **고정주입만**. = S1에서 검색은 거의 무의미(주입 성격).

**S2식 질의 = `"며칠째 계속 냄새가 나서 도저히 못 살겠어요"` (완결 문장):**
```
[방언 어휘]
- '냄새' → 냄섀              ← 질의의 '냄새'가 표제어 매칭되어 검색됨
[방언 문법 규칙]
- ...(고정 어미들)...
- 미치겠어 / 미치겠네 → 미치겠심더   ← BM25로 질의 관련 규칙 추가
- -는가요? → -는가예?
```
→ 문장 질의라 **어휘("냄새→냄섀") + 관련 규칙이 실제 검색됨**. = S2에서 검색이 살아남(retrieval 성격).

**이 A/B 대비가 논문의 injection(S1) vs retrieval(S2) 구분을 실물로 보여주는 근거다.**

### 예시 B — 제주, S2식 질의(문장)

**질의 = `"밤마다 냄새가 심해서 창문을 못 열어요"`:**
```
[방언 어휘]
- '냄새' → 내우살 / 내움이 / 내움살 / 내움새 / 내음살
- '열다' → 욜다
[방언 문법 규칙]
- 현재형 → -(으)ㄴ다, -나 (설명 축약)
- 의문형 종결어미 → -까/깡/꽈/꽝 / -가/강/과/광 (설명 축약)
```
→ 질의의 '냄새'·'열다'가 매칭되어 제주 방언 어휘가 다수 검색됨(권역별로 결과가 다름).

---

## 5. 요약
- 조건 차이는 `{knowledge_block}` 하나뿐. C0=없음, C1=예시, C_kb=RAG, C_kb+C1=둘 다.
- C1 예시는 권역당 6~7 표준어/방언 쌍 + 대화 1편(고정).
- C_kb 검색은 **어휘=정확매칭, 어미=고정주입, 관련 규칙=BM25**. **키워드 질의(S1)엔 어휘 검색이
  거의 안 걸리고, 문장 질의(S2)엔 어휘·관련규칙이 실제 검색됨** = injection vs retrieval의 실증.
