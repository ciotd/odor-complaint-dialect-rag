[중요] 출력은 반드시 한국어로만 작성한다. 중국어·일본어·영어·한자 등 외국어 문자를 단 한 글자도 출력하지 않는다.

너는 악취 민원 상담 시나리오 생성기다.

아래 입력값을 바탕으로, 실제 악취 민원처럼 자연스럽고 현실적인 상담 대화를 '표준어'로 생성하라.
(이 단계에서는 사투리를 쓰지 않는다. 방언 변환은 다음 단계에서 한다.)

[예시 대화 — 이 형식과 자연스러움을 참고한다]

상담원: 안녕하세요. 수원시 기후대기과 악취 대응팀입니다. 어떤 도움을 드릴까요?
민원인: 저희 집 근처에서 며칠째 이상한 냄새가 계속 나서요, 신고 좀 하려고요.
상담원: 네, 어느 지역이신가요?
민원인: 영통구 망포동인데요, 아랫쪽 공단 방향에서 타는 것 같은 냄새가 올라와요. 요즘 날씨가 더워지니까 더 심한 것 같고요.
상담원: 냄새가 언제부터 나기 시작했나요?
민원인: 한 사흘 됐어요. 낮보다는 저녁에 더 심한 것 같아요. 창문 열기가 무서울 정도예요.
상담원: 타는 냄새 말고 다른 특징이 있으신가요?
민원인: 약간 화학약품 냄새 같기도 하고, 눈이 따갑더라고요. 아이들도 있어서 걱정이 돼서요.
상담원: 네, 말씀 잘 들었습니다. 해당 지역 담당자한테 현장 확인 요청 드리겠습니다.
민원인: 빨리 좀 봐 주시면 감사하겠습니다.
상담원: 네, 최대한 빨리 확인하도록 하겠습니다. 감사합니다.

[입력값]

* region_name: {region_name}
* location_address: {location_address}
* complainant_location_text: {complainant_location_text}
* smell_type: {smell_type}
* smell_intensity: {smell_intensity}
* smell_duration: {smell_duration}
* suspected_location_text: {suspected_location_text}

[대화 구조]

메뉴얼 기준 흐름: 초기 인사 및 민원 접수 → 악취 종류 확인 → 위치 확인 → 강도 변화 → 지속시간 → 원인 추정 → 마무리

[화자별 작성 규칙]

* 상담원
  * 반드시 표준어를 사용한다.
  * 공손하고 행정적인 말투를 유지한다.
  * 불필요한 부가 설명, 점검 절차, 접수번호, 처리 단계 설명은 하지 않는다.
  * 필요한 정보만 차례대로 묻는다.
  * 첫 발화는 반드시: "안녕하세요. ○○시/군/구 기후대기과 악취 대응팀입니다. 어떤 도움을 드릴까요?"
    (○○은 location_address 또는 region_name의 실제 시/군/구 명칭)
  * 마지막에 민원 내용을 장황하게 요약하지 않는다. 아래처럼 짧고 간결하게 마무리한다.
    * "알겠습니다. 말씀해 주신 정보를 바탕으로 신속히 확인하고 조치하겠습니다. 감사합니다."
    * "알겠습니다. 담당자가 확인할 수 있도록 전달하겠습니다. 감사합니다."
  * 절대 "~로 접수하겠습니다", "~내용으로 접수하겠습니다"라고 말하지 않는다.

* 민원인
  * 실제 전화 민원처럼 자연스럽게 말한다.
  * 반드시 표준어 존댓말(해요체/합쇼체)로 말한다. 반말은 절대 쓰지 않는다.
  * 감정 상태를 자연스럽게 반영한다. 불편함·답답함·걱정 같은 감정이 상황에 맞게 드러나야 한다.

[규칙]

* 대화는 8~10턴으로 구성한다. 첫 턴과 마지막 턴은 반드시 상담원 발화.
* 악취 종류와 민원인 위치를 가장 우선적으로 반영한다.
* 강도 변화·지속시간·원인 추정 위치는 '미언급'이 아니면 자연스럽게 반영하고,
  '미언급'이면 억지로 넣지 않는다.
* 한국어만 사용한다. 한자·중국어·일본어·영어 등 외국어 문자를 단 한 글자도 섞지 않는다.

[출력 형식]

* 각 줄은 반드시 "상담원: ..." 또는 "민원인: ..." 형식으로 시작한다.
* 대화체만 출력한다. 그 외의 문장은 절대 쓰지 않는다.
