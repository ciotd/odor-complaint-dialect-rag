KG v2 조회 방식 × 생성 입력 형식 실험

목적
현재 KG v2를 고정한 채 조건을 포함한 지식 진술의 벡터 검색과 구간별 변환 계획을 검증한다.
KG 정보 추가, 기존 입력 분석의 의미적 수정, 생성 모델 교체를 함께 수행하지 않는다.

조건
A: 현재 v2_graph 조회 + 현재 입력 형식
B: 기존 형태·관계 조회와 조건부 지식 진술 벡터 검색 결합 + 현재 입력 형식
C: A와 동일한 후보 + 구간별 변환 계획
D: B와 동일한 후보 + 구간별 변환 계획

입력
기존 DEV 30개·LONG 8개와 새로 확정한 NEW 12개, 총 50개.
NEW 문장은 기존 오류 유형을 고려하여 작성한 추가 도전 문장이다.
생성 결과를 보기 전에 고정하지만 독립적으로 수집한 미지의 평가셋이나 정답 번역은 아니다.
기존 38개는 저장된 분석을 공유하고 NEW 12개는 Qwen으로 한 번 분석하여 네 조건에 공유한다.
스키마·원문 구간 검증에 실패하면 형식 오류만 알려 제한적으로 재시도한다.
Qwen 분석 자체의 언어적 정확성은 보증하지 않는다.

벡터 검색의 실제 범위
로컬 intfloat/multilingual-e5-small을 사용하며 추가 학습하지 않는다.
3,761개 지식 진술의 입력/출력 패턴, 문법 기능, 구조화된 조건, 사용 범위, 자연어 제약을 텍스트화한다.
긴 텍스트는 384토큰 단위로 나누어 임베딩한 후 평균·정규화한다. 진술 텍스트를 임의로 잘라 버리지 않는다.
원문 인용 전체를 임베딩하지 않는다. 인용은 원본 KG와 조회 기록에 보존하며 색인에는 출처·페이지를 연결한다.
어휘 검색 질의는 원문 기본형과 구간의 의미 설명을 사용한다. 의미가 비슷하다는 이유만으로 다른 표준어 기본형을 치환하지 않는다.
문법 검색 질의는 품사·문장 기능·어미·선어말·시제·높임·화행을 사용하며 문장 전체의 주제를 직접 검색하지 않는다.
기존 품사/기능/높임/구조화 조건 검사를 유지한다. 각 구간의 의미 검색 상위 12개를 추가 후보로 검사한다.
기존 조회 경로와 말투 우선순위는 유지하고, 그 내부에서 벡터 유사도로 순위를 결정한다.
따라서 이번 실험은 임베딩만으로 전체 KG를 자유롭게 조회·적용하는 방식이 아니다.
정확한 기본형 매칭, 기능 필터, 분석 오류, 기존 어휘 우선순위로 인한 한계는 남는다.

변환 계획의 실제 범위
같은 원문 구간에 연결된 후보를 묶고 보존할 문법 특징을 명시한다.
후보의 입력·출력 패턴, 조건, 제약, 사용 범위, 주석, 주장 상태와 출처 페이지를 유지한다.
기존에 제공하던 원문 분석과 형태소 분석도 네 조건에서 동일하게 유지한다.
원문 인용 본문 및 행정적 검사 로그는 생성 입력에서 생략하고 조회 로그에 보존한다.
생략 때문에 원문의 추가 맥락이 줄어들 수 있으므로 순수한 길이 효과나 무손실 재포맷 실험으로 주장하지 않는다.
이미 명시된 어미 조합 계획은 보존하되, 새로운 활용형을 임의로 합성하여 문헌 확인형처럼 제공하지 않는다.
규칙 조합 형태와 문헌에 실제 등장하는 형태를 구별한다.

고정 사항과 검사
Qwen 모델 ID·생성 설정·seed·system prompt는 동일하다.
A의 기존 38개 요청은 직전 v2_graph 요청과 완전히 같은지 검사한다. 생성은 이번에 새로 한다.
A/C와 B/D의 후보 ID·구간·조건·제약·범위·주석·출처 페이지·관계 경로의 동일성을 검사한다.
KG·기존 코드·기존 결과의 해시를 실행 전후 확인한다.
스키마 오류 재시도와 API 실패 재시도는 모두 기록한다. 결과의 품질을 보고 재생성하지 않는다.
문장별 네 조건의 실행 순서를 순환하여 배치 순서 편향을 줄인다. API 동시 호출은 2개이다.

평가
검색된 후보의 차이, 추가 경로, 후보 탈락 사유, 입력 길이를 기록한다.
의미·청자 높임·주체 높임·시제·부정·인용·이동 방향·문법·자연스러움을 구분해 결과를 검토한다.
문장 변화율이나 방언 어휘 수를 정확도로 간주하지 않는다.
모델의 검토는 탐색적 분석이며 독립적인 방언 화자 평가를 대신하지 못한다.
한 seed, 조건별 한 번 생성이므로 통계적 유의성이나 전체적인 일반화를 주장하지 않는다.
