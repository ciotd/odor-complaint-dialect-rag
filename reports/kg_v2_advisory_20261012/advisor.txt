제안: 어휘 후보마다 시간 순서·공간 위치·이동 방향·정도·가능성 등 의미 역할을 확인한다. 먼저→앞에는 문헌 예문을 후보 설명에 포함하고 지역·말투 적합성을 검토하되 일괄 금지하지 않는다. 원문 먼저를 유지하는 후보도 함께 허용한다. 선택적 치환은 필수 의미·높임 보존보다 낮은 우선순위를 둔다.
적용: 다른 행동/사람보다 앞서 하는 시간적 먼저 / 방향성이 있는 가다/오다, 도착점이 중요한 도착하다 / 잘 못 V와 못 V의 차이가 있는 구간
보존: 시간 순서, 공간/이동 방향, 정도 표현, 도착 완료 의미, 절의 필수 내용
모델 제안 예시:
  오늘은 시간이 없어서 먼저 갈게요. → 오늘은 시간이 없어가 먼저 갈게예.
  제가 매운 음식은 잘 못 먹는데 이건 괜찮네요. → 제가 매운 음식은 잘 못 묵는데 이건 괜찮네예.
반례/범위: 앞에 앉다라는 공간 표현을 먼저 앉다로 역치환하지 않는다. / 먼저/앞에 대응이 모든 방언 문맥에서 틀렸다고 단정하지 않는다. / 잘 못 먹다를 못 먹다로 축소하지 않는다. / 도착할 때까지를 올 때까지로 바꿀 때 도착점·완료 의미가 보존되는지 따로 검토한다.
불확실성: 문헌 대조자의 RYU PDF27 앞에 가요 예문 보고로 보아 시간적 앞에를 일괄 오류 판정했던 해석은 수정해야 한다. 본 조언자는 원문 이미지를 직접 확인하지 않았으므로 대조자 산출물을 근거로 연결해야 한다. 먼저와 앞에의 대상 말투 선호는 화자 검증 대상이다.
Qwen에 전달할 간결 지침 예시: 먼저→앞에는 문헌 예문과 대상 지역에 맞는 경우 선택적으로 적용. 먼저 유지도 허용. 잘 못 묵다의 잘과 못은 둘 다 보존.

ADV009 | DEV027, DEV028, DEV029, LONG002, LONG005, NEW012
문제: 인용 구문은 거의 표준어로 남고, C LONG002의 맛있더라→맛있대는 직접 경험/전언의 해석을 확인해야 한다. 문헌 대조자의 보고에 따르면 경상도 -대가 -더라에 대응하는 용법이 있어, 표준어의 전언 해석만으로 오류로 확정할 수 없다. Sonnet 온다고 했어→온다 카더라도 회상·증거성 비교가 필요하다.
제안: 인용하다/말하다 구문과 직접 경험 종결을 별도 기능으로 검색한다. 온다고 했어에 제안하는 온다 캤다는 인용 행위의 과거를 보존하는 후보로 검토한다. -대는 지역별 직접 경험 용법과 표준어 전언 용법을 구별하고, 조회된 근거가 어느 용법을 뒷받침하는지 표시한다. 검증 전에는 원문의 -더라를 유지하는 선택도 허용한다.
적용: 명시적인 발화 주체와 인용 내용이 있는 구간 / 더라가 화자의 경험/회상을 나타내는 구간 / 부정은 인용 내용인지 인용 의도 부정인지 확인된 경우
보존: 발화 주체, 인용 내용, 보고 시제, 직접 경험 대 전언, 부정의 작용 범위
모델 제안 예시:
  동생이 오늘은 늦게 온다고 했어. → 동생이 오늘은 늦게 온다 캤다.
  보기에는 조금 작아도 생각보다 달고 맛있더라. → 보기에는 쪼매 작아도 생각보다 달고 맛있더라.
반례/범위: 온다 캤다와 온다 카더라를 항상 동의어로 두지 않는다. / 버리라는 뜻이 아니었다는 인용 의도 부정이므로 버리지 말라는 뜻이었다로 단정해서 뒤집지 않는다. / 맛있더라는 표준어와 공유되는 형태라 그대로 두어도 된다.
불확실성: 캤다 결합 및 인용 축약의 지역별 범위는 문헌·화자 검증 대상이다. 직접 경험과 전언 구별은 현재 오류 분석의 보존 기준이다. 문헌 대조자가 NAMU_GRAMMAR PDF28의 더라→대/더라/더래 대응을 보고했으나 본 조언자는 원문을 직접 확인하지 않았으므로 구체 근거와 확정 판단은 대조자의 산출물을 따른다.
Qwen에 전달할 간결 지침 예시: 맛있더라는 화자의 경험 서술. 검증된 동일 기능의 방언 후보가 없으면 유지. 맛있대는 전언인지 방언 경험형인지 근거로 구별. 온다고 했어에는 온다 캤다를 검토하되 보고 과거와 발화 주체 보존.
