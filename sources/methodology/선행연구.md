# 선행연구

보유한 방법론 논문 **11편**의 검토 정리다. 앞선 5편은 한 편씩 설명하고 확인했으며, 나머지 6편은 사용자의 요청에 따라 일괄 검토하여 추가했다. 본문과 평가 관련 부록을 중심으로 확인했고, 주요 표·그림은 필요에 따라 PDF 화면과 대조했다. 실험을 재현하거나 공개 코드까지 감사한 결과는 아니다.

**검토 목적은 논문의 방법론을 그대로 채택하는 것이 아니라, 서론의 연구 배경·관련 연구·연구 필요성과 연구 설계의 선택을 뒷받침할 근거를 찾는 것이다.** 논문이 직접 확인한 결과, 우리 연구에 대한 해석, 아직 검증하지 않은 가설을 구분한다. 이 11편은 보유 자료 검토 범위이지, 해당 분야의 모든 선행연구를 망라한 체계적 문헌조사 결과는 아니다.

바로 볼 부분: **§1 전체 논문 요약 / §2 설계 근거 / §3 서론 흐름 / §5 새로 읽은 6편 상세 / §6 사용자가 제안한 배경 점검 / §7 서론 초안 / §8 다음 논의**.

## 1. 서론: 연구 배경과 관련 연구에 활용할 내용

| 논문 | 연구 내용과 확인된 결과 | 서론에서 활용할 논점 | 인용할 때 주의할 한계 |
|---|---|---|---|
| **EDC** — Zhang·Soh, EMNLP 2024 | 텍스트에서 관계를 추출하고, 관계의 의미를 정의한 뒤 같은 의미의 관계를 통합한다. 정답 triple 대조와 사람 평가로 구축 결과를 비교했다. | **외부 지식을 추출하는 것뿐 아니라, 서로 다른 표현을 공통 개념으로 정리하는 과정도 중요하다.** 문서별 지식을 통합하려는 우리 연구의 방법론적 배경으로 활용 가능. | 관계 통합으로 중복은 줄었지만, 통합 전보다 정확도가 항상 높아지지는 않았다. 방언 문법 체계나 생성 성능을 검증한 연구는 아니다. [원문](https://aclanthology.org/2024.emnlp-main.548.pdf) |
| **Can LLMs Really Learn… from One Grammar Book?** — Aycock 외, ICLR 2025 | 문법책을 설명문과 예문·번역 대응 부분으로 나누어 비교했다. 번역 개선의 상당 부분이 예문에서 나타났으며, 문법 설명의 추가 효과는 제한적이었다. | **문법 자원을 제공한 시스템의 성능 향상을 곧바로 문법 설명의 효과로 해석할 수 없다.** 어떤 종류의 지식이 실제로 기여하는지 분리할 필요성을 제시. | 예문 조건에도 형태소 풀이 등 문법 정보가 포함된다. 문법 지식 전체의 무용성을 입증한 것은 아니며, KG 기반 조건 조회를 시험하지 않았다. [원문](https://arxiv.org/pdf/2409.19151v2) |
| **Hire a Linguist! — LingoLLM** — Zhang 외, Findings of ACL 2024 | 형태 분석, 사전 검색, 문법 설명을 결합해 저자원 언어 번역과 일부 과제를 개선했다. 사전과 형태 분석의 기여도 확인했다. | **입력을 분석하고 그에 맞는 언어 지식을 제공하는 접근은 기존 연구에서도 시도되었다.** 우리의 입력 분석–지식 연결 흐름을 설명할 선행 접근. | 전체 효과를 문법책 하나의 효과로 분리하기 어렵다. 언어별 자원 조건이 다르고, 문법 KG의 필요성이나 자연스러운 경상도 방언 생성을 입증하지 않았다. [원문](https://arxiv.org/pdf/2402.18025v2) |
| **DIA-REFINE** — Park 외, LREC 2026 채택본 | 한국어 방언 생성 결과를 분류기로 판정하고 재생성한다. 후보 선택·피드백으로 목표 방언으로 분류되는 비율을 높였다. DFS·TDR을 제안했다. | **표준어→방언 생성에는 표준어 복사 문제와 평가 왜곡 문제가 있다.** 외부 피드백을 활용한 직접적인 한국어 방언 생성 선행연구로 설명 가능. | 의미 보존과 원어민 자연스러움은 평가하지 않았다. 생성 제어와 최종 평가에 같은 분류기를 사용하므로, 높은 점수를 독립적인 품질 검증으로 해석하면 안 된다. [원문](https://arxiv.org/pdf/2511.06680v3) |
| **Can LLMs Help Create Grammar?** — Spencer·Kongborrirak, COLING 2025 | 모클렌어 사전과 병렬 문장을 분석해 LFG 기반 XLE 문법 규칙과 어휘 항목을 작성한다. 예시 문장에 없던 단어 100개의 어휘 항목 중 86개를 정확하고 일관된 것으로 판단했지만, 영어 문법의 부적절한 전이와 뜻 누락도 보고했다. | **외부 문법 지식을 활용하는 것뿐 아니라, LLM으로 형식화된 문법 초안을 작성하는 연구도 존재한다.** 다만 형식화와 문법적 타당성 검증은 별개의 문제다. | 86/100은 문법 전체의 정확도가 아니다. 기존 연구를 바탕으로 기준 문법을 구성하고 사전·병렬 문장을 평가에 사용했으므로 정답 자료 없이 검증한 사례가 아니다. §6.1의 번역 향상은 기준 문법을 제공했다고 명시되어 있어 자동 생성 문법의 효과로 단정할 수 없다. [정식 출판본](https://aclanthology.org/2025.coling-main.681.pdf) |
| **GRAMMAR-LLM** — Tuccio 외, Findings of ACL 2025 | 형식 문법을 디코딩에 적용해 허용되는 토큰만 생성하게 한다. 계층 분류·합성 수어 글로스·AMR 파싱에서 형식 적합성과 과제 성능을 비교했다. 제약 조건에서 출력 적합성 100%를 보고했으나 AMRBART-large의 Smatch 개선은 0.789→0.790으로 작다. | **프롬프트 지시, 형식적 제약 준수, 과제의 실질적 정확도는 구분할 필요가 있다.** 생성 제어와 평가 축을 설명하는 보조 근거. | 여기서 grammar는 주로 출력 형식·허용 어휘를 제한하는 형식 문법이다. 경상도 방언 문법이나 자연스러움의 검증이 아니다. 수어 실험은 영상 생성이 아니라 합성 영어–ASL 글로스 자료다. [원문](https://aclanthology.org/2025.findings-acl.177.pdf) |
| **KAPING** — Baek·Aji·Saffari, MATCHING 워크숍 2023 | 질문과 관련된 KG triple을 검색해 프롬프트로 제공하는 추가 학습 없는 KGQA 방식. WebQSP/Freebase의 모델 평균 정답 엔티티 포함 정확도가 29.55→47.94로 향상됐다. 검색 실패 시에는 지식을 주지 않은 경우보다 나빠질 수 있었다. | **외부 지식을 제공하는 접근의 실증적 가능성과, 지식의 관련성을 선별해야 할 필요성**을 동시에 뒷받침한다. | 주 결과는 정답 엔티티가 제공된 입력 연결 조건이다. 자연어 생성의 문법성·자연스러움 지표가 아니며, triple 표현이 일반 텍스트보다 모든 모델에서 우수하지 않다. [검토본](https://arxiv.org/pdf/2306.04136v1), [출판 정보](https://aclanthology.org/2023.matching-1.7/) |
| **SURGE** — Kang 외, arXiv 2023 | 대화에 필요한 부분 그래프를 검색하고 그래프 인코딩·대조학습으로 생성에 반영한다. OpendialKG에서 전체 주변 지식 제공의 KQA F1 50.60에 비해 반지도 SURGE 57.63, 대조학습 SURGE 57.70을 보고했다. 사람 평가도 수행했다. | **지식 보유·관련 지식 검색·생성에서의 실제 반영은 별개의 문제다.** 검색과 활용을 분리해 평가할 근거. | 생성기와 검색기를 학습한다. 정답 대화와 KG를 가진 과제이며, KQA도 별도 학습한 QA 모델에 의존한다. KG 문법 구축이나 무학습 방언 생성의 직접 증거는 아니다. [검토본](https://arxiv.org/pdf/2305.18846v1) |
| **GraphRAG: From Local to Global** — Edge 외, arXiv 2024/2025 개정본 | 문서에서 그래프를 만들고 연결된 개체 집단을 요약하여 전체 자료에 관한 질문에 답한다. 두 코퍼스에서 각 125개 질문을 비교했고, GraphRAG의 벡터 RAG 대비 포괄성 승률은 약 72–79%였다. | **문서의 국소적 유사도 검색과 관계·계층을 활용한 정보 조직은 서로 다른 정보 요구를 지원할 수 있다.** 관계 기반 지식 조직의 방법론적 동기. | 전역 요약 과제의 결과다. 그래프 없이 전체 텍스트를 요약하는 비교군도 강했다. 승률은 LLM의 상대평가이며 사실 정확도가 아니다. 초기 그래프 구축 비용도 발생한다. [검토본 v2](https://arxiv.org/pdf/2404.16130v2) |
| **온톨로지 학습 기반 지식 그래프 구축** — 류민우·차시호, 컴퓨터교육학회 논문지 2022 | 도메인·지식·문장·접근 정보 등의 공통 온톨로지를 정의하고 한국어 형태소 분석 결과를 지식 구조에 연결하는 시스템을 구현했다. | **개별 지식을 공통 개념·관계 체계로 통합하려는 국내 구현 사례**로 활용할 수 있다. | 비교 실험·정량 오류율·상세 충돌 판정 사례가 제시되지 않았다. 중복과 의미 충돌을 일반적으로 해결했다고 인용하기 어렵다. 한국어 문장을 KG로 바꾸는 것과 한국어 문법 자체를 KG화하는 것은 다르다. [DOI](https://doi.org/10.32431/kace.2022.25.1.005) |
| **Low-Resourced Alphabet-Level Pivot-Based NMT** — Park·Park, Applied Sciences 2025 | 한국어 방언을 표준어로 정규화한 뒤 외국어로 번역한다. AI-Hub 5개 지역 자료에서 자모 단위 정규화와 피벗 번역의 개선을 보고했다. 경상도 정규화 BLEU는 자모 97.9, 형태소 93.5였다. | **한국어 방언 처리에서 어휘·형태 변이와 과제별 자원 부족이 실제 설계 문제로 다뤄진다.** 국내 방언 NLP 배경과 관련 연구에 직접 연결된다. | 표준어→방언 생성이 아니라 반대 방향의 정규화와 외국어 번역이다. 외국어 참조 번역은 Llama-3.1-8B가 생성했으며 정확하다는 가정에 의존한다. 높은 정규화 점수가 자연스러운 방언 생성을 입증하지 않는다. [원문 DOI](https://doi.org/10.3390/app15179459) |

## 2. 연구 설계에서 얻을 수 있는 아이디어

아래는 **연구 설계 선택을 설명할 근거와 후속 논의 질문**이다. 해당 알고리즘·도구·평가지표를 그대로 채택한다는 뜻이 아니다.

| 논문 | 가져올 수 있는 설계 아이디어 | 우리 연구에서 확인할 질문 | 적용 전에 필요한 조건 |
|---|---|---|---|
| **EDC** | 관계 이름만 맞추지 않고, **의미와 문맥을 정의한 뒤 문서 간 통합**. 구축 품질을 정확성·중복·누락 등으로 나눠 확인. | 여러 문헌의 같은 문법 개념을 연결하면서, 지역·용법·조건 차이는 보존할 수 있는가? | 평가 단위와 판단 기준이 필요하다. 현재 KG를 정답으로 삼으면 안 된다. 별도 평가 기반을 마련하지 못하면 구축 방법의 우월성을 주장하지 않는다. |
| **Grammar Book 연구** | **예문과 문법 설명·조건·관계의 기여를 분리**하는 비교. 예문만 제공하는 방법도 비교 후보로 고려. | 생성 개선이 문법 관계 활용 때문인가, 함께 제공한 예문 때문인가? | 비교 조건의 자료 출처·예문 품질·정보량을 명시해야 한다. 우리가 만든 미검증 예문을 원문 예문이나 평가 정답과 동일하게 취급하지 않는다. |
| **LingoLLM** | **입력 분석 결과를 지식 검색과 연결**. 어휘 뜻과 문법 기능을 구분하고, 분석기·사전·문헌 사이의 표기 불일치를 관리. | 생성 실패가 입력 분석 오류인가, 지식 검색 오류인가, 제공된 지식의 활용 오류인가? | 분석 결과와 KG가 공유할 개념·연결 규격이 필요하다. 실제 분석 결과와 정답 수준의 분석을 사용하는 실험은 구분해야 한다. |
| **DIA-REFINE** | **초기 생성 → 외부 검토 → 수정** 구조. 방언성·의미 보존·자연스러움을 별도 평가 축으로 고려. | 방언 특징을 강화할수록 의미가 바뀌거나 과장된 표현이 늘지는 않는가? 검토·수정이 실제 품질을 높이는가? | 수정에 사용한 검증자의 점수만으로 최종 성능을 주장하지 않는다. 독립적인 평가와 사람 판단을 검토하고, 후보 수·토큰·시간도 함께 비교해야 한다. |
| **Can LLMs Help Create Grammar?** | **형식 적합성·문법 내용의 타당성·생성 활용 효과를 분리해서 검증**. 공통 분석 틀을 사용하되, 다른 언어·변종의 규칙을 근거 없이 옮기지 않도록 확인. | 근거에 충실한 문법 지식인가? 형식상 정상인 지식이 실제 생성에도 도움이 되는가? | 이 논문의 예시 기반 문법 추론과 우리의 문헌 기반 지식 구조화는 구분해야 한다. 비교 기준과 상세 채점 절차를 별도로 설계해야 하며, 기준 문법의 효과와 자동 작성 문법의 효과도 분리해야 한다. |

| **KAPING** | **지식 없음·관련성 낮은 지식·관련 지식**을 구별해 지식 제공과 선택 효과를 분석. 실제 입력 분석과 기준 분석 조건도 구분. | KG 효과인가, 추가 정보의 효과인가? 입력 분석 실패와 검색 실패를 구별할 수 있는가? | 동일 모델·입력·근거 풀을 사용하고 검색된 정보의 내용과 길이를 기록한다. 무작위 지식 비교는 보조 진단이지 강한 텍스트 검색 비교군의 대체물이 아니다. |

| **온톨로지 학습 기반 KG** | **공통 개념 체계와 실제 기록을 분리**하고 기존 개념과 새 기록을 연결. | 이름이 같은 개념을 잘못 합치거나 문헌별 같은 개념을 중복 생성하지 않았는가? | 구현 그림만으로 지식 품질을 주장하지 않는다. 조사·서술어·문장 성분의 대응은 품사 태그만으로 확정할 수 없다. |
| **피벗 기반 방언 번역** | **자료 전처리와 과제 방향을 명시**하고 표준어와 방언이 동일한 입력을 따로 관찰. 문자·형태 변이와 문장 구조 오류를 구분. | 어떤 문장은 유지해야 하며 어떤 문장은 변환해야 하는가? 복사 비율과 과도한 변환을 함께 볼 수 있는가? | AI-Hub는 현재 독립 평가 후보라는 기존 정책을 유지한다. 합성 참조 문장을 사람 검증된 정답처럼 사용하지 않는다. |

## 4. 검증 설계와 관련해 별도로 기억할 내용

### Can LLMs Help Create Grammar?

- **구축 방식:** 약 1,000개 기본 어휘의 사전과 병렬 문장을 사용한다. 단어 분리 → 사전 뜻 연결 → 원래 어순에 따른 뜻 나열 → XLE 문법 규칙 작성 → 어휘 항목 작성 순서다. 사용 모델은 `gpt-4o-mini-2024-07-18`이며, 제공하는 문맥 정보의 조합을 비교한다. XLE는 형식 문법 구현 환경이지 KG 데이터베이스는 아니다.
- **문법 규칙 평가:** 기존 XLE 문법이 없어 Spencer(2022)의 미출판 문법 연구를 바탕으로 기준 문법을 구성하는 방식을 제시한다. 문법 규칙은 정성적으로 평가하며, 상세 채점 기준과 평가자 간 일치도 등의 보고는 충분하지 않다.
- **어휘 항목 평가:** 예시 문장에 없던 단어 100개를 사전과 수동 대조했고, 86개를 정확하고 일관된 것으로 판단했다. 이를 문법 체계 전체의 정확도 86%라고 인용하면 안 된다.
- **번역 평가:** 추가 병렬 문장 40개를 사용한다. §6.1은 제공한 문법을 `XLE gold standard grammar`라고 명시한다. 번역 성능 향상이 자동 작성 문법의 품질을 입증한다고 단정하지 않는다. 정식 출판본에도 이 표현이 유지된다.
- **일반화의 한계:** 모클렌어 한 언어를 대상으로 했으며, 굴절 형태가 없는 특성이 작업을 수월하게 했을 가능성을 저자들도 인정한다. 한국어 조사·어미·높임 등의 복잡한 결합까지 해결한 사례로 보지 않는다.
- **우리 연구에 대한 해석:** 기존 자동 구조 검사는 주로 형식 적합성을 확인한다. 이것만으로 문헌에 충실한지, 방언 문법으로 타당한지, 실제 생성에 도움이 되는지를 확인할 수는 없다. 별도 검증이 필요하다는 뜻이며, 이 논문이 완성된 검증 알고리즘을 제공한다는 뜻은 아니다.

## 5. 추가 검토한 6편의 상세 설명

### 6번째 — GRAMMAR-LLM

**질문:** 자연어로 지시하는 것만으로 출력 규격을 지키지 못한다면, 생성 가능한 토큰을 형식 문법으로 제한할 수 있는가?

**방법:** 사용자가 정의한 LL(prefix) 문법을 LL(1) 문법과 결정적 푸시다운 오토마톤으로 변환하고, 각 생성 단계에서 허용되지 않는 토큰을 막는다. 이는 문법 지식을 검색해 설명하는 방식이 아니라 디코딩 단계의 강제 제약이다. LL(prefix)는 LL(1)과 생성 능력이 동등한 표기 체계로 제시되며, 일반적인 자연언어 문법 전체를 표현한다는 뜻이 아니다.

**실험과 결과:**

- 계층 분류: Web of Science에서 2,000개 초록을 표본으로 사용한다. 7개 상위 범주와 134개 하위 범주의 올바른 경로를 출력하도록 제한한다. LLaMA-70B zero-shot의 하위 범주 micro-F1은 0.464→0.504, 형식 적합성은 80%→100%였다(Table 1).
- 영어→ASL 글로스: 합성 병렬 자료에서 2,000개를 평가한다. 8B 모델의 BLEU는 0.70→0.81, 허용 글로스 준수율은 39%→100%였다(Table 3). 실제 수어 화자의 자연스러운 수어 발화를 검증한 것은 아니다.
- AMR 파싱: 문장–AMR 자료 100개에서 구조 적합성과 정답 그래프 유사도를 평가한다. AMRBART-base의 Smatch는 0.559→0.577, large는 0.789→0.790이었다(Table 4). **형식 준수 개선과 의미 구조 정확도 개선은 같은 크기로 나타나지 않는다.**

**인용 역할:** 관련 연구의 ‘구조화된 생성 및 제약 기반 생성’에 배치하기 좋다. 연구 설계에서는 ‘자동 형식 검사 통과를 문법 지식의 정확성으로 해석하지 않는다’는 구분을 설명할 수 있다. 초기에 잘못 선택한 내용이 제약 아래서도 이어질 수 있다는 저자의 한계 논의도 참고할 만하다(§6).

**인용하지 않을 주장:** ‘문법 제약으로 자연스러운 경상도 방언을 보장한다’, ‘작은 모델은 언제나 큰 모델보다 나쁘다’. 이 논문은 해당 주장을 검증하지 않았다.

자료: [로컬 PDF](knowledge_injection/grammarllm2025.pdf), [출판본](https://aclanthology.org/2025.findings-acl.177.pdf). 확인 지점: §3, §4 Tables 1–4, §6.

### 7번째 — KAPING

**질문:** 모델을 추가 학습시키지 않고도, 입력 질문에 필요한 KG 지식을 제공하면 답변을 개선할 수 있는가?

**방법:** 질문의 개체를 KG에 연결 → 관련 개체 주변의 triple을 후보로 수집 → 질문과 triple의 임베딩 유사도로 선별 → triple을 텍스트로 프롬프트에 제공한다. 주 설정은 1-hop 후보 중 10개를 선택한다. 그래프에 저장했다고 해서 LLM이 그래프를 직접 실행하는 것은 아니다.

**실험과 결과:**

- 지식 없음·무작위 지식·빈번한 관계의 지식·LLM이 스스로 작성한 지식·관련 지식 검색을 비교한다.
- 본문의 초기 데이터 수와 달리, 부록 A.3의 필터링 후 평가 표본은 WebQSP/Freebase 1,582개, WebQSP/Wikidata 1,466개, Mintaka 2,814개다.
- WebQSP/Freebase의 11개 모델 설정 평균 정답 엔티티 포함 정확도는 지식 없음 29.55, 무작위 지식 37.22, KAPING 47.94다. 29.55→47.94는 **18.39퍼센트포인트** 차이이지 48퍼센트포인트 개선이 아니다(Table 1).
- 질문의 정답 엔티티를 포함하는 지식을 검색하지 못하면 지식 없는 조건보다 성능이 낮아질 수 있다(Figure 3). 실제 엔티티 연결기를 쓴 결과는 제공된 정답 엔티티를 쓸 때보다 낮다(Table 5).
- KG에서 얻은 같은 종류의 사실을 자유로운 설명문과 triple 문자열로 표현하는 비교도 수행한다. T5-3B에서는 설명문이 더 높고, T0에서는 triple 표현이 더 높다. **triple 표기 자체의 보편적 우월성은 확인되지 않는다**(Tables 11–12).

**평가상의 주의:** 주 정확도는 생성문에 정답 엔티티 하나가 포함되는지 측정하므로 부가적인 잘못된 설명을 모두 잡지 못한다. 부록에서 30개 질문의 사람 검토를 보완하지만, Table 9의 GPT-3 6.7B KAPING 행은 19+4+17=40으로 표본 30개 설명과 불일치한다. 해당 사람 평가 수치는 원자료 확인 없이 근거로 재사용하지 않는다.

**인용 역할:** ‘추가 학습 없이 외부 지식을 활용할 수 있다’, ‘관련 지식의 선택이 중요하다’, ‘입력과 지식을 연결하는 단계가 오류 원인이 될 수 있다’는 연구 배경·설계 근거로 적합하다. **지식 제공의 효과가 미미하다는 근거로 쓰면 안 된다.**

자료: [로컬 PDF](kg/kaping2023.pdf), [검토본 v1](https://arxiv.org/pdf/2306.04136v1), [MATCHING 2023 출판 정보](https://aclanthology.org/2023.matching-1.7/). 확인 지점: §3–5, Limitations, 부록 A.3, B.3–B.7. 초기 원고의 세부 수치와 표를 검토했으며 출판본 전체의 동일성까지 검증한 것은 아니다.

### 8번째 — SURGE

**질문:** 필요한 지식을 검색하는 것과, 검색한 지식을 실제 답변에 충실히 반영하는 것을 함께 개선할 수 있는가?

**방법:** 대화 맥락에 맞는 부분 그래프를 검색하고, 관계를 반영한 그래프 표현을 생성 모델의 입력 표현에 결합한다. 그래프와 생성 텍스트의 대응을 학습하는 대조학습도 사용한다. 주 생성기는 T5-small이며 검색기와 생성기를 학습한다. ‘unsupervised’라는 변형 이름은 **검색 정답 라벨을 사용하지 않는다는 뜻**이지, 대화 정답이나 학습 자체가 없다는 뜻이 아니다.

**실험과 결과:**

- OpendialKG와 KOMODIS 대화 자료를 사용한다. OpendialKG는 약 15,000개 대화와 약 119만 triple의 KG를 제공하며, 대화 세션을 70/15/15로 분리한다.
- OpendialKG의 KQA F1은 지식 없음 20.69, 주변 지식 전체 제공 50.60, 반지도 SURGE 57.63, 대조학습 SURGE 57.70이다(Table 1). 모델의 모든 변형이 모든 평가 축에서 같은 순위를 보이는 것은 아니다.
- 정답 지식을 제공하는 oracle 조건도 있어 검색의 영향을 분리한다. 관계를 고려하지 않는 인코딩과의 비교는 관계 정보의 기여를 살펴보는 실험 사례다(Tables 6, 11).
- 사람 평가에서는 30개 응답 표본을 대상으로 46명의 평가자가 맥락 일관성·정보성·유창성을 3점 척도로 평가했다. 정보성 점수와 KQA F1의 Pearson 상관은 0.42로 보고됐다(§5.4, 부록 G). 이를 완벽한 평가 일치로 해석하지 않는다.

**KQA의 의미와 한계:** 한 질문에 정답 문장이 여러 개일 수 있다는 문제를 고려해, KG에 있는 가능한 정답 개체들로 QA 문제를 만든다. BERT QA 모델을 약 20만 합성 예제로 학습하고 생성 결과에서 정답을 찾게 한다. 그러나 부록 E.1은 QA 평가기 자료를 전체 OpendialKG에서 구성했다고 명시하므로, 생성 평가와의 자료 독립성이 충분히 확보됐는지는 별도 확인이 필요하다. KQA는 정답 지식과 학습된 평가기를 필요로 하며 ‘정답 없는 만능 검증’이 아니다. 전체 문장에 다른 거짓 정보가 없는지도 자동 보장하지 않는다.

**인용 역할:** 관련 연구의 ‘지식 기반 대화 생성’과 설계의 ‘검색/활용/최종 품질 분리’에 적합하다. 문법 KG 자체의 정확도를 평가한 연구로 인용하지 않는다. 학습 실험은 단일 실행으로 보고됐다는 점도 유의한다(부록 E.3).

자료: [로컬 PDF](kg/surge2023.pdf), [검토본 v1](https://arxiv.org/pdf/2305.18846v1). 확인 지점: §3–5, 부록 A, E.1–E.3, F, G. 확인한 arXiv 기록에서는 심사 중 초고로 표시되어 있어 학회 게재 논문으로 단정하지 않는다.

### 9번째 — GraphRAG: From Local to Global

**질문:** 개별 문서 일부가 아니라 자료 전체의 주제와 관계를 종합해야 하는 질문에 어떻게 답할 것인가?

**방법:** 문서 → 개체·관계 그래프 → 연결이 밀접한 집단(community)과 그 계층 → 집단별 요약 → 질문에 대한 부분 답변 → 전체 답변 순서다. 우리의 ‘입력 문장의 문법 기능에 맞는 조건 조회’와 동일한 작업은 아니지만, **관계에 따라 자료를 조직하는 것이 검색·종합 방식에 영향을 준다**는 연구 배경으로 연결할 수 있다.

**실험과 결과:**

- 약 100만 토큰의 팟캐스트와 약 170만 토큰의 뉴스 코퍼스를 사용한다. 각 코퍼스에 LLM으로 만든 전역 질문 125개가 있다.
- 그래프 요약 4수준(C0–C3), 그래프 없이 전체 원문을 map-reduce 요약하는 TS, 벡터 검색 SS를 비교한다. 각 LLM 호출의 문맥 예산은 8k로 맞추지만 총 호출 수·총 토큰은 같지 않다.
- 정답 답변 대신 기준별 쌍대 비교를 사용하고, 각 비교를 5회 반복한다. 지표는 포괄성·다양성·판단 도움·직접성이다.
- GraphRAG는 SS보다 포괄성 승률 약 72–79%를 보이지만, TS도 SS 대비 약 80–83%다. 따라서 ‘그래프여서만 좋아졌다’고 해석하면 안 된다(Figure 2).
- TS 대비 GraphRAG의 일부 수준에서 추가 개선과 질의 시 요약 토큰 감소가 나타난다. 이 절감은 전체 수명주기 비용이 아니라 질의에 투입되는 요약량의 비교다. 팟캐스트 그래프 인덱싱에는 별도로 281분이 들었다(§4.1.3).
- 두 번째 실험은 답변에서 추출한 사실 주장 수와 군집 수로 포괄성·다양성을 보완 측정한다. 이 지표에서는 GraphRAG와 TS 사이에 통계적으로 유의한 차이가 없었다(§5.2).

**평가상의 의미:** 정답 문장 없이도 명확한 기준에 따른 상대 비교는 가능하다는 사례다. 그러나 판정 프롬프트는 질문과 두 답변을 받아 비교하며 원문 전체와 대조하는 사실 검증 절차는 아니다. 주장 수가 많다는 것이 정확하다는 뜻도 아니다. 저자도 허위 내용 비율 비교를 추가 과제로 남겼다. 이 연구를 근거로 ‘LLM 둘이 동의하면 KG가 정확하다’고 결론 내릴 수 없다.

**인용 역할:** 서론에서는 관계 기반 정보 조직의 가능성, 관련 연구에서는 그래프 기반 RAG, 연구 설계에서는 강한 비그래프 비교군과 평가 축 구분의 사례로 적합하다. 그래프 없이 수행하는 TS 비교군의 존재가 특히 중요하다.

자료: [로컬 PDF](kg/graphrag2024.pdf), [검토본 v2](https://arxiv.org/pdf/2404.16130v2). 확인 지점: §3–6, Figure 2, Tables 2–4, 부록 A, C, F, G. 보관본은 2024년 초판이 아닌 2025년 개정본이다.

### 10번째 — 온톨로지 학습 기반 지식 그래프 구축

**질문:** 서로 다른 도메인에서 모은 지식을 공통 구조로 연결하고, 중복과 의미 충돌을 어떻게 관리할 것인가?

**방법:** Domain, Knowledge, Sentence, Grounding, Description 등의 공통 모델을 정의한다. 한국어 텍스트를 형태소 분석하고 문장 성분에 대응하는 지식으로 정리하여 온톨로지에 연결한다. Apache Jena, khaii, Protégé 기반 구현을 제시한다. 여기서 Grounding은 주로 웹 지식의 위치·프로토콜·접근 방법이며, 현대 LLM 평가에서 말하는 ‘근거 충실성’과 같은 용어로 읽으면 안 된다.

**실제로 확인된 결과:** 온톨로지 그림, 처리 흐름, 중복 판정 의사코드, 구현 화면을 제공한다. 그러나 평가 표본 수·정답 기준·중복/충돌 판정 정확도·기존 방법과의 정량 비교는 본문에 제시되지 않는다.

**비판적으로 볼 부분:** Table 1은 명사·동사와 기존 주어·술어를 비교하는 단순한 절차다. 의사코드 6행은 `VV != subject`라고 적혀 있으나 설명에서는 술어 비교를 말해 표기 불일치도 있다. 품사가 명사라는 사실만으로 주어·목적어 등의 문장 성분과 의미 역할을 확정할 수는 없다. 따라서 이 알고리즘이 복잡한 문장의 의미 충돌이나 방언 문법의 조건 충돌을 해결한다고 주장할 근거는 부족하다.

**인용 역할:** 국내의 ‘공통 온톨로지를 통한 지식 통합 구현 사례’로는 쓸 수 있다. 하지만 이 논문만으로 우리의 노드·관계 설계나 검증 알고리즘이 타당하다고 주장하지 않는다. 11편 중에서는 **핵심 성능 근거보다 보조 관련 연구**에 적합하다.

자료: [로컬 PDF](kg/ontologykg2022.pdf), [DOI](https://doi.org/10.32431/kace.2022.25.1.005). 확인 지점: §2–5, Table 1, Figures 6–8(PDF pp.4–5).

### 11번째 — Low-Resourced Alphabet-Level Pivot-Based NMT

**질문:** 한국어 방언과 외국어의 직접 병렬 자료가 부족할 때, 표준어를 중간 단계로 활용할 수 있는가?

**방법:** 방언 → 자모 단위 정규화 모델(minGRU 인코더 + GRU 디코더) → 표준어 → 기존 번역기/LLM → 외국어. 표준어→방언 생성 연구와 방향이 반대다.

**실험과 결과:**

- AI-Hub의 경상·전라·제주·강원·충청 5개 지역 자료를 사용한다. 짧은 문장, 일부 잡음, 표준어와 방언이 완전히 같은 쌍 등을 제외한다. 경상도 정규화 학습 쌍은 260,494개, 테스트는 14,181개다(Table 3).
- 자모·형태소·SentencePiece·byte-level BPE를 비교한다. 경상도 정규화 BLEU는 자모 97.9±0.4, 형태소 93.5±0.8, SentencePiece 76.3±4.0이다(Table 4). 점수 97.9가 97.9%의 문장이 완벽하다는 뜻은 아니다.
- 정규화 모델 학습은 3회 반복해 평균·표준편차를 제시했다. 자모 모델은 약 1.2M 매개변수다. 작은 전용 모델의 정규화 성과를 현재 로컬 LLM의 방언 생성 성능과 직접 비교하지 않는다.
- 방언→영어에서 EXAONE의 전체 평균 chrF++는 직접 번역 38.08→피벗 번역 39.05, BERTScore는 90.70→90.91이다(Table 7). 이는 지식 제공 실험이 아니라 입력 정규화를 추가한 번역 실험이다.

**핵심 한계:** 외국어 정답 번역이 없어서 표준어를 Llama-3.1-8B로 번역한 결과를 참조로 삼고, 이를 정확하다고 가정한다(§5.3). 따라서 피벗 결과가 사람 기준으로 더 정확한지, 참조를 만든 표준어 기반 번역과 더 비슷해진 것인지 구별에 한계가 있다. 사람의 자연스러움 검증을 대체하지 않는다.

**인용상의 주의:** 서론의 ‘모든 방언이 같은 문법을 공유한다’는 단순화는 우리의 문법 연구 전제로 가져오지 않는다. 표준어와 상당 부분을 공유한다는 사실과 조사·어미·통사 조건이 완전히 같다는 주장은 다르다. ‘하다→카다’와 같은 예시도 문맥과 방언 원문 검증 없이 새 KG 규칙으로 추가하지 않는다.

**인용 역할:** 한국어 방언 처리의 과제별 자원 제약, 어휘·형태 변이, 정규화 연구라는 배경에 적합하다. 경상도 생성 실패의 직접 측정이나 ‘외부 지식은 효과가 작다’는 증거로는 부적합하다.

자료: [로컬 PDF](dialect_generation/pivotnmt2025.pdf), [출판 DOI](https://doi.org/10.3390/app15179459). 확인 지점: §1–5, Tables 3–9. 출판사 웹 본문은 재확인 시 429 응답이었으며, 본문·수치 검토는 보관된 출판 PDF로 수행했다.

## 6. 사용자가 제안한 연구 배경에 대한 점검

### 6.1 주장별 판단과 연결할 근거

| 제안한 서론 주장 | 판단 | 논문에서 안전하게 쓸 표현·필요한 근거 |
|---|---|---|
| 한국어에는 지역 방언이 존재한다. | 출발점으로 타당하다. | 짧게 제시하고 경상도 문법 원문 등 언어학적 출처를 연결한다. 왜 자연스러운 방언 생성이 필요한지도 덧붙인다. |
| 고성능 LLM도 경상도 방언을 어색하게 생성한다. | 가능한 문제 제기지만 구체적인 모델·입력·평가 근거가 필요하다. | DIA-REFINE의 생성·평가 문제와 연결하고, 우리 baseline에서 관찰한 오류율과 실제 예시로 보완한다. 모든 상용 모델에 일반화하지 않는다. |
| 로컬 sLLM에서는 더 심할 것이다. | 검증할 가설이지 전제가 아니다. | ‘자원 제약이 있는 로컬 모델에서도 방언 생성 품질을 확보할 필요가 있다’고 동기를 설명한다. 로컬 배포 여부와 모델 크기는 별개이며, 크기 외에 학습 자료·조정·양자화·프롬프트 차이가 있다. |
| “오늘은 시간이가 없어서 내일 또 가겄다” 같은 출력이 나온다. | 문제를 설명하는 사례 후보이나 현재 발화만으로 실측 결과라고 기록할 수 없다. | 모델·원문 입력·프롬프트·생성 설정·원본 출력 로그를 확인해야 실제 사례로 사용한다. ‘시간이가’의 결합, 지역 일관성 등을 검토하되 문헌·화자 판단 없이 각 표현의 지역을 단정하지 않는다. |
| 개별 사례가 아니라 선행 측정 또는 baseline이 필요하다. | 타당하고 중요하다. | 개발용 오류 탐색과 최종 평가 세트를 분리한다. 유리한 사례만 골라 문제를 과장하지 않고 전체 표본 수와 오류 유형별 비율을 제시한다. |
| 왜 못하는가? 방언이 저자원이기 때문이다. | 원인을 하나로 확정하면 논리적 비약이다. | ‘관련 학습·평가 자원의 제약이 한 요인일 수 있다’고 표현한다. 방언 전체를 무조건 저자원이라고 묶지 말고 표준어 대비 자료, 지역·세대·사용 맥락, 과제별 병렬 자료와 검증 자료의 부족을 구분한다. |
| 기존 외부 지식 제공의 효과는 제한적·미미하다. | 전체 선행연구에 대한 요약으로는 부정확하다. | LingoLLM·KAPING·SURGE는 개선을 보고한다. Grammar Book 연구가 보여주는 것은 특정 조건에서 문법 설명의 추가 기여가 제한적이라는 결과다. ‘효과는 있지만 어떤 내용과 제공 방식이 기여하는지 더 검증해야 한다’로 연결한다. |
| 그래서 KG를 적용한다. | 방법 가설로 타당하지만 앞 문장만으로 필연적으로 도출되지는 않는다. | 문법 기능·형태·결합 조건·예외·범주 간 관계를 연결하고, 입력 분석 결과에 따라 필요한 부분을 조회하려는 설계 이유를 명시한다. 이것이 다른 표현 방식보다 유리한지는 비교 실험 대상이다. |

### 6.2 KG와 RAG의 관계

RAG는 외부 정보를 검색하여 생성에 제공하는 접근이고, KG는 지식의 표현·조직 방식이다. 따라서 KG에서 지식을 조회해 LLM에 제공하는 시스템도 넓은 의미의 RAG에 해당할 수 있다. 논문에서는 다음처럼 구별하는 편이 명확하다.

- 프롬프트만 사용하는 생성.
- 텍스트 근거를 검색하여 제공하는 생성.
- 문법 KG의 관계와 조건에 따라 근거를 조회하여 제공하는 생성.

지식이 JSON 파일에 저장되었는지, 그래프 DB에 저장되었는지 자체가 핵심 비교 변수가 아니다. **어떤 문법 정보를 표현하고, 어떻게 연결하고, 입력에 맞춰 무엇을 선택해 제공했는지**가 핵심이다. 같은 관계를 관계형 DB의 조인으로 구현할 수도 있으므로, 저장 엔진만 바꾼 결과를 KG의 의미적 효과로 주장하지 않는다.

### 6.3 기존 v1/v2의 역할

시행착오는 연구 질문을 구체화한 과정으로 기록할 수 있다. 그러나 통제되지 않은 과거 시행착오를 새 비교 실험처럼 포장하지 않는다. 논문에서 성능 근거로 쓰려면 입력·모델·프롬프트·자료·평가·로그의 재현 가능성을 점검해야 한다. 그렇지 않으면 개발 배경이나 설계 변경의 동기로만 기술한다. 이번 문헌 검토에서 과거 실험 로그의 진위·수치까지 재검증한 것은 아니다.

## 7. 서론 문장 초안과 관련 연구의 배치

### 7.1 서론 초안 — 결과를 미리 가정하지 않는 버전

한국어의 지역 방언을 자연스럽게 생성하려면 지역적 표현 특성을 반영하면서도 입력의 의미와 발화 맥락을 유지해야 한다. 한국어 방언 처리 연구에서는 어휘·형태 변이와 과제별 병렬 자료의 부족이 주요 문제로 다뤄져 왔다([Park·Park, 2025](https://doi.org/10.3390/app15179459)). 표준어에서 방언으로의 생성 연구는 목표 방언이 충분히 반영되지 않는 문제와, 기존 자동 평가가 이를 제대로 드러내지 못할 수 있음을 보여준다([DIA-REFINE](https://arxiv.org/pdf/2511.06680v3)). 이에 본 연구는 경상도 방언 생성에서 의미 보존, 방언 표현의 적절성, 문장 자연스러움을 구분해 살펴본다. **[우리 baseline 측정 후: 대상 모델·표본·오류 유형·오류 비율 및 대표 사례 삽입.]**

외부 언어 지식은 이러한 문제에 대응할 수 있는 한 접근이다. 사전·형태 분석·문법 설명을 활용한 저자원 언어 처리 연구에서는 성능 개선이 보고되었다([LingoLLM](https://arxiv.org/pdf/2402.18025v2)). 다만 문법책의 효과를 분석한 연구는 예문과 문법 설명의 기여가 다를 수 있음을 보여주므로, 자료를 제공했다는 사실만으로 문법 지식의 효과를 단정할 수 없다([Aycock 외, 2025](https://arxiv.org/pdf/2409.19151v2)). 또한 KG 활용 연구들은 관련 지식을 선별하는 과정과 그 지식을 생성에 반영하는 과정의 중요성을 각각 보여준다([KAPING](https://arxiv.org/pdf/2306.04136v1), [SURGE](https://arxiv.org/pdf/2305.18846v1)).

이러한 논의를 바탕으로 본 연구는 경상도 방언의 문법 기능, 표현 형태, 적용 조건 및 범주 간 관계를 명시적으로 연결한 문법 KG를 검토한다. 문헌 간 개념 통합과 관계 기반 정보 조직에 관한 선행 접근([EDC](https://aclanthology.org/2024.emnlp-main.548.pdf), [GraphRAG](https://arxiv.org/pdf/2404.16130v2))을 참고하되, 이들의 성과를 방언 생성의 성과로 일반화하지 않는다. 연구 질문은 **입력 문장의 문법 분석에 따라 관련 지식을 조회·제공하는 방식이, 프롬프트만 사용하는 방식 및 텍스트 지식을 제공하는 방식과 비교해 로컬 LLM의 의미 보존과 자연스러운 경상도 방언 생성을 개선하는가**이다.

이 문단은 논증 방향을 잡기 위한 초안이다. KG의 우월성, 오류 원인의 인과관계, 분야 최초성은 아직 주장하지 않는다. 특정 문법 범주들의 상호작용에 대한 설명은 방법론 논문이 아니라 보유 방언 문헌의 실제 근거와 연결해야 한다.

### 7.2 관련 연구를 나눌 수 있는 네 묶음

| 관련 연구 묶음 | 중심 논문 | 우리 연구와 연결할 논점 |
|---|---|---|
| 한국어 방언 처리·생성·평가 | DIA-REFINE, 피벗 기반 방언 번역 | 과제 방향, 방언 변이, 표준어 복사와 과도한 변환, 평가의 한계 |
| 외부 언어 지식과 문법 자원 활용 | LingoLLM, Grammar Book 연구, Can LLMs Help Create Grammar? | 언어 지식의 효과와 구성, 설명·예문의 역할, 지식 작성과 검증의 구별 |
| KG 구성·검색·생성 | EDC, KAPING, SURGE, GraphRAG, 온톨로지 학습 기반 KG | 문헌 통합, 관련성, 관계 표현, 검색·활용 분리 |

11편을 서론에 모두 넣을 필요는 없다. 서론에는 논증에 꼭 필요한 논문을 배치하고, 알고리즘과 평가의 세부 차이는 관련 연구·연구 설계에서 다룬다. 특히 온톨로지 구현 논문은 보조 사례이며, 강한 정량 성능 근거로 취급하지 않는다.

## 8. 다음 논의와 연구 설계의 근거

아래는 이번 검토에서 도출한 제안이며, 실험을 실행하거나 설계를 확정한 것이 아니다.

1. **주장–근거 확정:** §6의 문장 중 문헌으로 뒷받침할 것과 우리 baseline으로 측정할 것을 구분한다. ‘방언 오류의 모든 원인을 규명한다’가 아니라 ‘어떤 지식 제공 방식이 품질을 개선하는지 검증한다’로 범위를 정하면 현실적이다.
2. **baseline의 오류 정의:** 표준어 복사, 목표 지역과의 일관성 문제, 조사·어미 결합 문제, 문법 기능/의미 변경, 과도한 방언화 등을 잠정 분류한다. 원문과 같아도 자연스러운 경우가 있으므로 복사 자체를 오류로 두지 않는다. 지역 표현도 단일 정답 어휘로만 판정하지 않는다. 정의는 방언 근거와 사람 검토로 확정한다.
3. **강한 비교군:** 동일 로컬 모델에서 프롬프트만 / 동일 근거 풀의 텍스트 검색 / 문법 KG 조회를 기본 후보로 둔다. 지식 선택 효과와 표현 형식 효과를 더 분리하려면, 동일하게 선택한 지식을 설명문과 구조화 형태로 전달하는 비교를 추가할 수 있다. 근거는 KAPING의 제공·검색·표현 비교와 GraphRAG의 비그래프 TS 비교다. 단순히 약한 프롬프트를 골라 KG에 유리하게 만들지 않는다.
4. **공정성:** 모델·입력·생성 설정·예시 제공 여부·근거 출처·정보 예산을 기록한다. 입력 분석·검색·검토 호출까지 포함한 총 비용은 별도로 보고한다. 상용 모델을 비교한다면 현재 선택한 특정 모델과의 과제별 격차를 말하고, ‘상용 모델 전체와 동급’으로 일반화하지 않는다. 같은 문법 입력 분석을 텍스트 검색에도 제공하는 비교는 KG 고유 효과를 분리할 때 고려한다.
5. **지식 구축 품질:** 형식 검사와 별도로 원문 충실성·조건/예외 보존·지역/맥락 범위·문헌 간 통합의 적절성을 확인한다. 구축 방법을 비교하려면 동일 원문 구간과 사전 정의된 기준으로 독립 검토해야 한다. 생성한 KG를 자기 자신의 정답으로 삼지 않는다. 이 기준이 마련되지 않으면 구축 우월성 실험은 주장하지 않는다.
6. **생성 평가:** 의미 보존·지역적 적절성·자연스러움을 구별한다. 정답 문장 없이 쌍대 평가를 하는 것은 가능하지만, LLM 평가자의 방언 판단 능력은 별도로 확인해야 한다. 순서 무작위화, 시스템 이름 비공개, 동점 허용, 근거가 있는 오류 기록, 사람 평가와의 대조를 검토한다. 두 모델의 합의는 참고 신호이지 정답 인증이 아니다. 이 제안은 GraphRAG의 상대 평가와 SURGE의 사람 평가를 참고한 우리의 설계 제안이며, 해당 논문에 모든 절차가 구현돼 있었다는 뜻이 아니다.
7. **보류할 확정:** 평가 표본 수, 사용할 모델, 검증자 역할, KG 내부 변형 비교의 수는 아직 확정하지 않는다. 효과 크기·평가 부담·예산과 사용자의 이해를 확인한 뒤 정한다. 이 문헌 검토 당시에는 추가 모델 실행이나 새로운 KG 작성을 시작하지 않았다. 후속 사용자 승인으로 직접 KG 작성은 진행 중이며, 생성 비교 실행과는 구별한다.

### 9.1 연구 방향에 대한 판단

**후속 사용자 설명에 따른 초점 정정:** 출발점은 검색 성능 개선이 아니라 경상도 방언의 문법 체계를 공통 문법 범주·형태·기능·결합 관계로 그래프화하고, 그 체계를 활용하여 자연스러운 생성을 시도하는 것이다. 아래 선택·조합은 이를 구현·평가할 수단으로 제안한 것이며 주목적을 대신하지 않는다. 세부 지역 구분은 중심 과제가 아닌 근거 범위 보존을 위한 보조 정보다. [연구 목적과 원칙](../../연구미팅.md).

연구를 폐기할 근거는 없지만 KG의 필요성과 구축 지식의 타당성은 아직 입증되지 않았다. 초점은 단순히 그래프를 만드는 것이 아니라 **문법 기능·표현·조건을 연결해 필요한 지식을 선택하고 표현 조합을 개선하는 것이 최종 생성 품질에 기여하는가**이다. 지식 선택/조합과 생성 품질은 별도 가설로 구분할 수 있다. 이 표현은 제안이며 최종 합의 전이다.

문법 범주가 많다는 사실만으로 KG의 필연성은 도출되지 않는다. 실제 원문에서 질문 해석·서술부 유형·높임·선어말어미 등의 상호작용 사례를 확인하고, 텍스트 검색 대비 무엇을 추가로 제공하는지 설명해야 한다. 문법적 가능성과 화자의 자연스러운 사용도 구분한다.

### 9.2 우선 논의할 세 가지

1. **KG의 기여:** 추가 지식의 효과와 관계·조건을 이용한 선택/조합의 효과를 구분한다.
2. **지식 품질:** 원문 충실성, 조건의 강도, 용법·지역 차이를 보존하는 문헌 통합, 분석 결과와의 연결, 공백 처리를 판단한다. 완벽함을 전제하지 않고 검증 범위와 사용 기준을 정한다.
3. **공정한 비교:** 전체 시스템 효과와 KG 고유 효과는 다른 비교 질문이다. 동일 원문 풀·분석·예문·정보량·총 비용을 통제/기록한다.

주 비교 후보는 프롬프트만 / 텍스트 검색 / KG 조회다. 보조 비교로 동일 선택 지식의 전달 형식, 예문 통제 아래 문법 정보의 추가 기여, 기준 분석 대 실제 분석을 검토할 수 있다. 임의로 엣지만 삭제하면 의미 정보 손실과 관계 효과가 섞이므로 제거 대상부터 정의한다. 모두 실행·확정 전이다.

KG 구축 단계의 비교도 가능성은 있으나 아직 준비되지 않았다. 동일 원문에서 문서별 작성과 공통 개념 통합을 비교하려면 평가 단위·정답 판단 기준·독립 검토를 먼저 마련해야 한다. 노드 감소나 LLM 합의만으로 구축 우월성을 주장하지 않는다. 시행착오는 별도 개발 이력으로 보존한다.

### 9.3 AI-Hub 예비 진단과 해석 범위

사용자는 AI-Hub 대응 어절을 문장으로 묶은 약 100개 입력으로 로컬 모델의 prompt-only 출력을 관찰하자고 제안했다. 예비 진단으로 타당하되 다음 조건이 필요하다.

- 원 발화·화자·순서·대응을 보존하고 문장 재구성 기준을 명시한다.
- 생성 모델에 방언 참조를 보여주지 않는다. 참조는 유일 정답이 아니다.
- 특정 모델/프롬프트/표본의 오류만 주장하고 전체 LLM 실패·지식의 필수성·KG 효과·저자원성의 인과를 결론 내리지 않는다.
- 실패 사례만 고르지 않고 표본 구성과 전체 결과를 보고한다. 개발에 활용하면 최종 미사용 평가셋과 분리한다.
- 로컬 구성 스크립트는 0.8초 무음·길이·편집거리·방언 어절 수 선별을 사용한다. 대표 표본이나 확정 문장 경계가 아니며 화자 전환·원 구간 추적·수동 수정 이력을 추가 점검해야 한다.

로컬 후보 파일의 존재만 확인했으며, 이 문서 업데이트에서 생성·평가를 수행하지 않았다. AI-Hub는 계속 문법 근거가 아닌 독립 평가 후보다.

### 9.4 현재 지식에 대한 제한적 점검

이 평가를 처음 작성했을 때 새 작성본은 67건이었다. 2026-09-17 후속 작성본은 331건, 직접 방언 근거는 양지현(2021)을 포함한 7종이다. 실제 통합·대조 관계 50개를 작성했으나 전수 작성·조건 검토 및 충분한 문헌 간 의미 통합이 입증된 것은 아니다. 독립 검토와 생성 승인은 여전히 0건이다. 최신 상태는 [작성검토.md](../../current_kg/grammar/작성검토.md)를 따른다.

높임법 기록 `GYS-H001`의 장터 관찰이 `market_familiar` 필수조건으로 저장된 부분은 원문 재대조 대상이다. 사용이 관찰된 장면을 문법상 필요조건으로 바꿨는지 확인해야 한다. 이번에는 오류를 확정하거나 기록을 수정하지 않았다. 설명용 예문도 자기 지식의 독립 검증 근거로 사용하지 않는다.

이 논문 11편 중 우리의 방언 문법 KG를 그대로 검증할 완성된 알고리즘은 찾지 못했다. 활용 가능한 것은 검증 질문·비교 설계의 관점이며, 실제 판단 기준은 별도로 설계해야 한다.
