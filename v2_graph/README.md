# v2-graph — 지식그래프 기반 조건부 문법 방언 변환 (경북 KG · 경상 평가)

이 문서가 v2 연구의 정본(SSOT). v1(RAG 파편검색)은 `../docs/research_scope.md`, 전체 지도는 `../PROJECT_MAP.md`.

## 목표
표준어→방언 변환에서, 흩어진 규칙을 통째 주입(파편 덤프, v1식 RAG)하는 대신 **문장 자질에 맞는 문법
서브그래프만 focused하게 주입**하면 변환이 개선되는가? (경북 문법 KG 기반, training-free)

## 차별점 (novelty 포지션)
- **KG(focused 서브그래프) vs RAG(파편 덤프)** 정면 대조.
- **training-free** (자질이 이산적이라 학습된 검색기 불필요 — SURGE·EDC 대비 경량화).
- v1(파편 RAG 변환, S2)의 실패(§10.2b-3)를 KG 조건부 변환으로 대체 → 직접 대조.

## 과제 방식 (확정)
- **표준어→방언 변환(conversion)**, **발화(문장) 단위.** QA/대화생성 아님. AI-Hub 표준-방언 쌍의 표준 발화를
  입력받아 경북 방언으로 변환, 방언 참조와 비교.
- **악취 민원 도메인 미사용** (표준 대응 텍스트 부재). 일반 방언 변환.
- 파이프라인: 표준 발화 → ①자질 추출(종결법·의문종류·결합환경 + 화자 높임) → ②KG 조회(정확매칭)
  → ③서브그래프 focused 주입 → LLM 변환. 대조군 = 전체 규칙 파편 덤프.
- ②는 이산 자질 정확매칭(벡터 불필요). 애매함은 ①(자질추출: kiwi/규칙/LLM, TBD)에 집중.

## 스코프 (문법 범위)
- **핵심 = 종결어미** (조현준2018 backbone, 조건부 구조 풍부: 판정/설명·계사/용언·높임체계 → KG showcase).
- **+ 조사·기타 문법**(주격/속격/공동격·선어말·부정 등): **기존 경북 소스(v1 경상 원본 문법론)에 있는 대로만**
  편입. 새 소스 안 찾음, **빈 곳은 빈 대로**(커버리지 플래그). 조사는 대부분 무조건 치환(flat)이라 자연성엔
  기여하나 "KG>리스트" 증거는 종결어미에서 나옴.

## KG backbone / 평가 데이터 (경북 vs 경상 — 재프레이밍 2026-08-25)
- **KG = 경북**(조현준2018, 종결어미 체계·판정/설명·빈도). 신뢰도 최상.
- **평가 = AI-Hub 139 "경상도" 코퍼스** (`../dialect_corpus/aihub/…경상도…2인발화.zip`). 표준-방언 발화쌍
  다수(샘플 300파일 2487쌍).
- ⚠️ **AI-Hub는 경북/경남 미분리**(province 전부 `gs`, city코드 있으나 코드북 없음). 즉 **평가 코퍼스에
  경남 발화 일부 혼입.**
- **결정(A):** 경상 통합 그대로 사용 + 위 프레이밍. 근거: 경북/경남이 **핵심 조건부 체계를 공유**(판정/설명·
  높임)라 주 결과 영향 제한적. 차이는 특정 어미 형태에 국한 → 평가 노이즈.
- **완화:** exact-match 대신 **reference-tolerant 평가**(어미 마커 기반/LLM judge). 정답 다형성·경남 혼입 페널티 완화.
- **한계 명시:** 우리 KG는 경북만이라 **경남 고유형 생성 불가**(경남 타깃 참조는 miss). modest(핵심 공유).
