# v2-graph — 지식그래프 기반 조건부 문법 방언 생성 (경북)

이 문서가 v2 연구의 정본(SSOT). v1(RAG 파편검색)은 `../docs/research_scope.md`, 전체 지도는 `../PROJECT_MAP.md`.

## 목표
자연스러운 방언 생성에서, 흩어진 규칙을 통째 주입(파편 덤프)하는 대신 **문장 자질에 맞는 문법 서브그래프만
focused하게 주입**하면 생성이 개선되는가? (**경북 방언** 국한 사례연구)

## 동기 (v1에서 이어짐)
- v1 §10.2: 모델이 주입한 파편 규칙의 79~89%를 무시(출력측 병목).
- v1 §10.4 (b)해석: RAG(쿼리조건부 파편검색)는 방언의 체계적·쿼리무관 특성과 구조적으로 안 맞음.
- → 파편 대신 **조건부 구조화 문법(KG)**을 focused하게 주면 병목이 줄지 않을까? (RQ)

## 방법 (SURGE식 (b), training-free)
1. 입력 문장에서 **자질(feature) 추출**: 종결법(서술/의문/명령/청유)·상대높임·의문사유무(판정/설명)·결합환경
   (계사/용언) 등 (이산·유한).
2. 경북 **문법 KG에서 그 자질에 맞는 규칙 노드(서브그래프) 검색.** 자질이 이산적이라 **학습 없이 규칙 매칭**
   으로 정확히 뽑음 (SURGE는 개방형 사실이라 학습된 GNN 검색기가 필요했으나 우리는 불필요 — 우리 강점).
3. 서브그래프를 **프롬프트에 focused하게 삽입** → LLM이 방언 변환·생성.
4. 대조군 = v1식 파편 덤프(전체 규칙 주입).
