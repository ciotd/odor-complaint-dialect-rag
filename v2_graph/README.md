# v2-graph — 치환 + 조건부 문법 KG 기반 방언 변환 (경상)

이 문서가 v2 연구의 정본(SSOT). v1(RAG 파편검색)은 `../docs/research_scope.md`, 전체 지도는 `../PROJECT_MAP.md`.

## 목표 (2026-08-26 재프레이밍)
표준어→방언 변환에서, **광범위 치환**(어휘·음운·조사·연결어미)에 더해 **문장 자질에 맞는 조건부
종결어미 KG(서브그래프)**를 얹으면 변환이 개선되는가? — **ablation으로 KG의 순수 기여 측정.** training-free.

## 왜 재프레이밍했나 (이전 "종결어미 전용"에서 전환)
- 이전엔 KG가 특별한 **종결어미·경북만** 좁혔는데, 이는 **방법이 유리한 곳만 고른 cherry-picking 위험**
  (v1 metric-shopping과 같은 실수)이고, 실제 방언은 **어휘·음운·조사·연결어미 치환이 큰 비중**이라
  종결어미만으론 "반만 방언"이 됨.
- 그래서 **치환(넓게) + 조건부 KG(어미)를 한 시스템으로** 두고, **자연 문장 전체에서** KG가 실제로
  기여하나를 정직하게 본다.

## 차별점 (novelty)
- **조건부 종결어미 KG**(SURGE식 서브그래프, training-free): 치환만으론 못 하는 **문맥 의존 어미 선택**
  (판정/설명→나/노, 계사/용언→가/나 등).
- **ablation**(치환만 vs 치환+KG)으로 KG 순수 기여를 공정 측정.
- **focused KG vs 전체 덤프** 대조(원래 novelty): 조건부 어미 부분에서 focused 검색이 덤프보다 나은가.

## 과제 방식
- **표준어→방언 변환, 발화(문장) 단위, 현실적 풀 문장.** (QA/대화생성/악취도메인 아님)
- 파이프라인: **치환(넓게 적용)** + [① 자질추출(kiwi+규칙) → ② KG 조회(조건 필터) → ③ 조건부 어미
  서브그래프 주입 → ④ LLM 생성]. ②는 이산 자질 정확매칭(벡터 불필요).

## 스코프
- **과제 = 경상 방언 변환** (풀 문장, 자연 분포).
- **치환 레이어 = 어휘·음운·조사·연결어미** — v1 경상 자원 재사용(`data/dialect_kb/vocab_clean.jsonl`,
  경상 원본 음운·조사 등). ⚠️ 품질 불완전해도 **ablation에선 양쪽(±KG)에 공통 투입되어 상쇄** →
  v1을 괴롭힌 어휘 품질 편향이 여기선 결과를 왜곡 안 함.
- **조건부 KG = 경북 종결어미** (조현준2018 backbone, `data/kg_rules.jsonl` 39규칙). 경북 특정은 유지하되
  전체 과제는 경상 변환.

## 평가 설계
- **주 비교(ablation):** 치환만 vs 치환+KG → **KG 순수 기여.**
- **부 비교:** 치환+KG(focused) vs 치환+전체덤프 → focused가 덤프보다 나은가.
- 단위: 발화. **현실적 풀 문장**(통제 입력 + AI-Hub 표준 샘플). 전체 성능 + **분해 보고**(조건부 어미
  케이스에서 KG 효과 집중 — 여기가 KG가 특히 기여할 곳).
- 지표: reference-tolerant(어미 일치/LLM judge 쌍대) + 소규모 사람 judge. 순환성 회피(KG=조현준 ≠ 평가=AI-Hub).
- ⚠️ 정직: KG 순수 기여가 **작게 나올 수도** 있음(조건부 어미가 소수) → 그래도 분해 보고하면 valid.
