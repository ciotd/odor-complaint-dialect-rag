# 경북 방언 문법 KG — 정식 스키마 (v1)

확정일: 2026-08-25. 범위: 경북(경상북도) 종결어미. 이 스키마가 모든 노드/엣지 추출의 기준.
근거: 조현준(2018) §Ⅱ(종결법·상대높임 체계) + §Ⅲ 추출 경험(의문법). 원칙: **사실=논문 / 구조화=AI / 검증=사용자.**

---

## 1. 노드 타입

| 노드 타입 | 값(예) | 속성 |
|---|---|---|
| **종결법** | 서술 · 의문 · 명령 · 청유 | — |
| **상대높임** | 하이소체 · 하소체 · 하게체 · 해라체 · 해체 · 해요체류 | 격식\|비격식, -이-결합여부 |
| **의문하위** | 판정 · 설명 | (의문법 + 하게·해라 등 구분 등급에만 연결) |
| **결합환경** | 계사 · 용언 | (-가/고 vs -나/노를 가르는 축) |
| **지역** | 경북서부 · 경북중동서부 · 경북중동동부 (선택) | 하위방언 분포 |
| **규칙노드 R** | R_id (예: R_해라_판정_용언) | 출처, 빈도, 사용양상, 검증상태 |
| **어미형** | 실제 종결어미 (-나, -노, -ㄴ가, -니껴 …) | 표준\|방언 |

## 2. 엣지 타입

```
조건 엣지:  조건.종결법 · 조건.높임 · 조건.의문종류 · 조건.결합환경 · 조건.지역
산출 엣지:  산출어미
메타 엣지:  속성.* · 출처
```
- **조건 엣지**: (R) ─조건.X→ [조건노드]. R이 성립하는 조건.
- **산출 엣지**: (R) ─산출어미→ [어미형]. R이 낳는 형태(복수 가능).
- **출처 엣지**: (R) ─출처→ "조현준2018 §3.1.2.4 표28 p141".

## 3. 규약 (필수)

### 3.1 Reification (R 규칙노드)
어미는 여러 조건에 동시 의존(종결법+높임+판정/설명+결합환경) → 단일 트리플 불가.
**모든 규칙은 R 노드로 만들고**, 조건 노드들이 R로 들어가고 R이 어미로 나감.

### 3.2 조건부 연결 규칙 (등급 의존)
- **판정/설명**: **하게체·해라체에만** 연결(뚜렷). **하이소체·하소체는 미연결**(한 어미가 둘 다 = "미구분" 속성).
- **결합환경(계사/용언)**: 해라체 의문의 -가/고(계사) vs -나/노(용언)처럼 필요한 곳에만.
- 근거 없는 조건 임의 부착 금지.

### 3.3 출처(provenance) 필수
모든 R에 **출처(논문·절·표·페이지)** 박기. 출처 없는 규칙 금지. (v1 "출처 0%" 재발 방지)

### 3.4 속성
- **빈도**: 논문 표의 코퍼스 사용 수(있으면).
- **사용양상**: 혼용 · 사멸(고령층만) · 표준침투(표준형 우세) · 지역편중 등.
- **지역분포**: 하위방언 편중(선택).

## 4. 검증상태 플래그

| 상태 | 뜻 | 누가 |
|---|---|---|
| **①추출-미검증** | AI가 논문서 추출, 사람 확인 전 (기본값) | AI |
| **②검증-출처대조** | 사람이 노드↔논문 원문 대조, 오전사 없음 확인 (현실적 주 검증) | 사용자 |
| **③검증-원어민** | 경북 화자/전문가가 자연성까지 확인 (최상·선택) | 사용자 |
| **④불확실** | AI가 자신 없음 → 우선 검토 | AI |
| **충돌** | 소스끼리 상이 → 병기+표시 | AI |

**기본값 = ①추출-미검증** (확인 안 된 건 "검증됨"으로 새지 않음).

**④불확실로 찍는 기준(규칙화):**
- pypdf 텍스트/표 정렬이 깨지거나 모호
- 코퍼스 1회(hapax) 형태 (예: 해라체 의문 -데이 1례)
- 논문 자신이 유보("추측"·등급 혼란)
- 조건 배정이 애매(어느 높임인지 논쟁)

**활용:** 플래그로 필터 — 생성엔 ②이상만 / ④만 모아 검토 / ①비율=KG 성숙도.

## 5. 인스턴스 예 (경북 의문·해라체)

```
(R_해라_판정_용언)
  조건.종결법→[의문]  조건.높임→[해라체]  조건.의문종류→[판정]  조건.결합환경→[용언]
  산출어미→[-나]
  속성.빈도="2226(대계, 전지역 최다)"  속성.사용양상="보편"
  출처→"조현준2018 §3.1.2.4 표28 p141"   검증상태="①추출-미검증"

(R_해라_설명_용언) … 조건.의문종류→[설명] … 산출어미→[-노] (빈도 3063) …
(R_해라_판정_계사) … 조건.결합환경→[계사] … 산출어미→[-가] (계사결합, "주인이가?")
```
