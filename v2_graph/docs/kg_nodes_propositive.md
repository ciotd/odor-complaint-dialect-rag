# 경북 방언 KG 노드 — 청유법 (종결법=청유)

출처: 조현준(2018) §3.1.4(격식)·§3.2.4(비격식), 표37~44·55. 추출 2026-08-25. 스키마 `kg_schema.md`.
청유법은 판정/설명 없음. 조건 = {청유, 높임}. 검증상태 전부 ①추출-미검증.

## 격식체
```
(R_청유_하이소) {청유, 하이소체}  방언: -이시더/-입시더      표준: -입시다
   속성: -ㅂ시다 + 높임소 -이- = -입시더. 표37 p171.
(R_청유_하소)   {청유, 하소체}    방언: -시더/-ㅂ시더, -시데이   표준: -ㅂ시다
   속성: -시더는 하이소체 서술 -시더와 동형(통사결합으로 구분). 표39 p176.
(R_청유_하게)   {청유, 하게체}    표준: -세   (방언형 없음)   표41 p183.
(R_청유_해라)   {청유, 해라체}    방언: -제   표준: -자   표43 p187.
```

## 비격식체
```
(R_청유_해)    {청유, 해체}   -아/어  (특별 형태 없음; -지 문맥의존, ④불확실)  §3.2.4.1 p222
(R_청유_해요)  {청유, 해요체} -요, -시요, -지요
(R_청유_해예)  {청유, 해예체} -지예       표55 p223
```

## 메모
- 청유법도 방언형 빈약(하게체=표준 -세만, 해라체=-제). KG 조건부 이득 제한적.
- -시더(청유 하소)↔-시더(서술 하이소), -제(청유 해라)↔-제(서술/의문 해체) 동형 다수 → 통사·문맥 의존, 검증 우선.
