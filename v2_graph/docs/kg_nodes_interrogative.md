# 경상(경북) 방언 KG 노드 — 의문법 (종결법=의문)

출처: 조현준(2018) 「경북방언의 종결어미 연구 — 한국구비문학대계(경북편)」, §3.1.2, 표21~28.
추출·구조화: 2026-08-25. **사실=논문 / 구조화=AI / 검증=사용자(미완).** 라이선스: 사실 인용만(PDF 재배포 X).
범위: 경북(경상북도). 경남과 일부 다를 수 있음.

포맷: `(R_id) {조건들} → 어미  [빈도/속성]  (출처)`
조건 축: 종결법 · 상대높임(하이소체/하소체/하게체/해라체) · 의문사유무→판정/설명 · 결합환경(계사/용언) · 지역.

---

## 핵심 조건부 규칙 (KG 정당화)
의문법 어미 = **f(높임 × 의문사유무[판정/설명] × 결합환경[계사/용언] × 지역)**.
- 의문사 **없음 → 판정(ㅏ계열)**, 의문사 **있음 → 설명(ㅗ계열)**. (최명옥1980; p136·140)
- 판정/설명 구분: **하게체·해라체 = 뚜렷 / 하이소체·하소체 = 미구분(한 어미가 둘 다)**. (p117 각주126, p135)

# 표준형
(R_해라_표준)     {의문, 해라체}                 → -(으)냐/느냐(2207), -니(33)  [의문사 유무로 판정/설명]

## 통사 특성 메모 (생성 시 중요)
- **-가/고 vs -나/노 선택 = 결합 대상**: 계사·지정사·있다/없다 → -가/고 / 용언(동사·형용사)+선어말어미 → -나/노.
- 판정/설명은 **의문사 유무로 결정**(누구·뭐·어디·왜·언제 → 설명 → ㅗ계열).
- 표준형(-ㅂ니까/-냐)이 실사용 빈도 매우 높음(1980년대 표준침투) → 방언형만 강제 시 실제 분포와 괴리 가능.

## 정직성/불확실
- 빈도는 논문 표 그대로 옮김(경북 하위지역 합계). 오전사 가능 → 검수 필요.
- 하소체(§3.1.2.2) 미정독. 감탄법·수사의문 등 주변 현상 미포함.
- 지역축(서부/동부)은 논문 방언구획 요약 — 생성에 쓸지는 이후 결정.
