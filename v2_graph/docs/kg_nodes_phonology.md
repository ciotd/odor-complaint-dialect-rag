# 경북/경상 방언 KG 노드 — 음운 (domain=음운)

출처: v1 경상 원본(gyeongsang_grammar.json 음운론) — 민백과·경북방언특징·경주방언 등. 추출·구조화 2026-08-26.
스키마: `kg_schema.md`. **사실=원본/구조화=AI/검증=사용자.**
⚠️ 종결어미와 **조건축이 다름**: 음운 도메인의 조건 = **음운환경**(위치·앞뒤소리·대상·지역/세대).
적용은 자모 단위라, 파이프라인에선 **LLM에 규칙설명을 주어 적용**(자모 엔진 미구현). 규칙 상호작용(경음화+구개음화 등)은 1차엔 LLM에 맡김.

포맷: `(id) 조건{위치·환경} → 변환(from→to)  [예]  (출처) 검증`

---

## A. 조건부·환경 명확 (강, 출처 좋음)
```
(P_경음화)   조건{위치=어두/첫음절}           예사소리 ㄱㅂㄷㅅㅈ → 된소리 ㄲㅃㄸㅆㅉ
   [과자→까자]  (첫음절 강세)  검증①
(P_구개음화_ㄱㅎ) 조건{위치=어두, 환경=i/j 앞}   ㄱ→ㅈ, ㅎ→ㅅ
   [길→질, 힘→심, 흉→숭]  (민백과, 예외 거의 없음)  검증①
(P_어간말ㅊ)  조건{위치=명사 어간말}            ㅊ → ㅌ(치조폐쇄)
   [꽃→꼳, 낯→낱, 빛→빋]  (민백과)  검증①
(P_유기음화회피) 조건{환경=어간말 ㅂ/ㄷ/ㄱ + 어미 ㅎ}  유기음화 안 함(연음)
   [밥하고→밥하고(묵)]  (민백과)  검증④ (효과 미묘·표기변화 작음)
(P_이중모음_어두자음) 조건{위치=어두, 환경=자음 있음}  이중모음 → 단모음
   [과자→가자]  (경북특징)  검증①
```

## B. 조건부이나 변이·좁음
```
(P_이중모음_단모음) 조건{대상=외/의/류}          → 애/으/루
   [외무부→애무부]  검증①
(P_i움라우트)  조건{환경=후행 i}                후설(오/아) → 전설(외/애)
   [소고기→소괴기]  검증④ (변이)
(P_여_에)     조건{대상=ㅕ}                     ㅕ → ㅔ
   [경상도→겡상도]  검증④ (변이)
(P_ㅡㅜ통합)  조건{대상=ㅡ/ㅜ, 지역/세대 변이}    ㅡ↔ㅓ 중간음 통합
   [이수근→이수건]  검증④ (변이)
(P_ㅂ규칙화)  조건{대상=ㅂ불규칙 용언, 지역=동부}  -워 → -어(규칙활용)
   [더워→덥어]  검증④ (지역)
(P_ㅆ_ㅅ)    조건{지역=낙동강 동쪽}              ㅆ → ㅅ (ㅆ 음소기능 없음)
   [쌀→살]  (민백과)  검증① (지역조건)
(P_e_i)      조건{대상=ㅔ(e)}                   e → i
   [메느리→미느리, 며느리→미느리]  (경북특징)  검증①
(P_비어두h_k) 조건{위치=비어두}                  h → k
   [앓아도→앍아도]  (경주방언)  검증④ (좁음)
(P_Cu장음h)  조건{대상=2음절 Cu: 동사어간, 세대}  장음삭제+h첨가
   [바꾸고→바꿎꼬(60대이하)]  (경주방언)  검증④ (좁음·세대)
```

## 이관/보류
- (→어휘 dict) **오늘→올, 지금→짐, 내일→낼** = 특정 단어 축약(규칙 아님) → 어휘 치환으로.
- (보류 ④) **-습니다→-시엄니다** 구개음화 변이 = 미심쩍음, 검증 전 제외.

## 요약
- 음운 KG 규칙 **13개**(A 5 + B 8). 조건축 = 음운환경.
- 검증: ①(출처 명확·환경 명확) 8개 / ④(변이·좁음·미묘) 5개 → ②검증 우선순위 표시.
- 적용: LLM 규칙설명 방식. 상호작용은 관찰 대상.
