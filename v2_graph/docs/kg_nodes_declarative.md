# 경북 방언 KG 노드 — 서술법 (종결법=서술)

출처: 조현준(2018) §3.1.1(격식)·§3.2.1(비격식), 표13~20·45~48. 추출·구조화 2026-08-25.
스키마: `kg_schema.md`. **사실=논문/구조화=AI/검증=사용자.** 검증상태 전부 ①추출-미검증.
서술법은 **판정/설명·계사/용언 분기 없음** → 조건 = {서술, 높임}뿐 (의문법보다 단순).

## 격식체

### 하이소체 서술 (표13, p79)
```
(R_서술_하이소) {서술, 하이소체}
  방언: -니더/-ㅂ니더, -디더/-ㅂ디더, -시더, -ㄹ시더, -이더, -리더, -니데이/-ㅂ니데이, -오리더
  표준: -ㅂ니다/-습(십)니다, -ㅂ디다/-습디다, -(옵)나이다, -오리다
  속성: -ㅂ- 수의적(-니더~-ㅂ니더). -심더/-ㅁ더=‘-니-’탈락형. -니데이=‘-이’ 강조결합.
  출처: 조현준2018 표13 p75~79
```

### 하소체 서술 (표15, p94)
```
(R_서술_하소) {서술, 하소체}
  방언: -구마, -구매(-꾸매)     ← ⚠️ 감탄 성격(서술/감탄 경계). 불확실 표시
  표준: -소                    (‘-겠-/-었-/있다’와 결합)
  속성: 형태 적음, 방언/표준 대립 약함.
  검증상태: -구마/-구매 = ④불확실(감탄 겹침)
  출처: 조현준2018 표15 p93~94
```

### 하게체 서술 (표17, p100)
```
(R_서술_하게) {서술, 하게체}
  방언: -ㅅ세
  표준: -ㄹ세, -ㅁ세, -네, -다네, -ㄹ라네, -구려
  속성: -세/-ㅅ세 ↔ 표준 -ㄹ세 대응. -ㅁ세=하이소체 -ㅁ시더의 낮은 등급.
  출처: 조현준2018 표17 p99~100
```

### 해라체 서술 (표19, p109)
```
(R_서술_해라) {서술, 해라체}
  방언: -ㄹ다, -ㅅ다, -ㄹ끼다, -데이, -래이, -(ㄹ)꾸마
  표준: -다, -ㄴ다, -아라/어라
  속성: -데이=하이소체 -니데이 절단형. -래이=표준 -아라/어라 대응.
        -구마=감탄, -꾸마=약속(기능 분화). 방언형이 하게체보다 많음.
  출처: 조현준2018 표19 p107~109
```

## 비격식체

### 해체 서술 (표45, p193)
```
(R_서술_해) {서술, 해체}
  방언: -ㄹ낀데, -라, -래, -제, -지러, -끼
  표준: -데, -ㄴ데, -ㅂ갑데, -지
  속성: -지(표준)~-지러(방언). -제=억양따라 의문 가능. -끼=표준 -ㄹ게 대응.
        ⚠️ -지러/-제 등은 여러 등급(하소·하게·해라·해)에 걸쳐 논쟁(충돌).
  검증상태: -지러/-제 = 충돌(등급 논쟁)
  출처: 조현준2018 표45 p191~193
```

### 해요체/해예체/해여체 서술 (표47·48, p203) — 구조 = 해체 + 요/예/여
```
(R_서술_해요) {서술, 해요체}
  -요, -네요, -데요, -라요, -래요, -세요, -제요, -지요, -지러요, -거든요, -께요, -(ㄹ)끼요, -니더요, -ㅂ니더요
  빈도(표48): -아/어요 7596(압도적), -래요 1007, -라요 714, -데요 214, -네요 204
(R_서술_해예) {서술, 해예체}  -예, -네예, -데예, -라예, -래예, -지예, -거든예, -께예
(R_서술_해여) {서술, 해여체}  -여, -더여, -래여
  속성: 전부 ‘해체 + 요/예/여’ 구조. 해요체 최다, 해예/해여 소수.
  출처: 조현준2018 표47·48 p201~203
```

## 메모 (생성 시)
- 서술법은 조건이 {서술, 높임}뿐이라 KG 이득이 의문법보다 작음(조건부 분기 적음). KG 강점은 의문법(판정/설명)·경어체계 선택에 집중.
- 표준형(-ㅂ니다/-다/-아어요)이 빈도 압도적(표준침투). 방언형 강제 시 실제 분포와 괴리 주의.
- -구마/-꾸마(감탄/약속), -지러/-제(등급 논쟁)는 검증(②) 우선 대상.
