# 첫 Claude 체크포인트: 부정 절

상태: **1차 외부 AI 검토 수신 → Codex 원문 재대조·수정 완료**.
수정본의 Claude 재검토와 사람 검토는 아직 수행하지 않았다. 운영 Rule 승인도 없다.
논문 전체 318건 중 부정 절 9건만 검토했다. 나머지 309건은 이번 검토 통과 대상이 아니다.

## 이번에 실제로 실행한 것

- 검토 대상: RYU2014-S0187~S0195, 9건.
- 참고용 관련 Claim: 7건. 이 7건을 별도로 전수 검토했다는 뜻은 아니다.
- 원문: PDF 2·4·5·7·19·21·22·25·26쪽의 자동 추출 텍스트.
- Claude에는 원문 PDF 이미지를 직접 보여주지 않았다. 표 판독을 독립적으로 완전히 검증한 것은 아니다.
- 모델 도구 없음, 사용자/프로젝트 확장 비활성화, 호스트 파일시스템 읽기 전용.
- 기존 Claim 파일과 실행기를 쓰기 모드로 여는 시험은 EROFS로 차단됐다. 실제 바이트 쓰기·truncate는 시도하지 않았다.
- Claude 실행 직후 원본 입력 해시 불변을 확인했다. 그 뒤 Codex가 아래 수정을 수행했다.
- packet은 수정 전 스냅샷이고, 실제 장부만 Codex가 수정했다. 기존 packet을 새 장부로 덮어쓰지 않았다.

## Claude 결과와 Codex 판단

Claude 판정은 pass 8건, revise 1건이다. 여기서 pass는 해당 검토자의 근거 확인이며,
사람 승인이나 모든 구조적 결함이 없다는 보증이 아니다. 특히 S0194는 pass를 받았지만
문헌 내 차이 때문에 기존 hold를 유지했고, 구조 필드도 Codex가 별도로 보완했다.

| 항목 | Claude 의견 | Codex 판단·반영 |
|---|---|---|
| 몬→못 변화, S0190 / ISS-1 | 변화 설명의 PDF 21쪽 누락 | 수용. 본문은 21쪽, 표는 22쪽이므로 [21,22] / [75,76]으로 수정 |
| 안 단형 부정, S0187 / ISS-2 | 22쪽은 불필요하게 넓은 인용 | 수용. 본문·예문이 있는 [21] / [75]로 좁힘 |
| -지 않다, S0194 / ISS-3 | 초록과 본문의 세대 차이로 hold 유지 | 수용. hold 유지, 기존 원문 문제 S0313과 연결 |
| 누락 Claim | 추가 누락 없음 | 제공 구간에 대한 검토자의 결론으로만 기록. 완전성 보증이나 전체 논문 검증으로 해석하지 않음 |

## Claude 답변 자체에서 수용하지 않은 부분

`review.json`의 `source_facts` 중 못/몬 표 설명은 숫자를 **표준어 못의 사용률**이라고
지칭했다. 그러나 원문의 해당 숫자 칸은 **방언 사용 비율**이다. 이는 Reviewer의 오류이므로
수용하지 않았다. 원 응답은 감사 가능하도록 그대로 보존했으며, 해당 내용을 Claim 근거로
옮기지 않았다. 수치는 사용자 방침대로 신규 Claim에 추가하지 않았다.

또한 소수 제보자에게 확인했다는 사실과 그 비율의 산출 방식이 검증됐다는 것은 다르다.
Reviewer의 한계 설명을 통계 산출법의 근거로 삼지 않는다. “AI가 모두 동의했다”는 이유로
원문 해석을 확정하지 않는다는 원칙을 이번에도 적용했다.

## Codex가 추가로 확인·보완한 내용

- S0188(못의 단형 부정 분류), S0195(-지 말다)의 본문 근거가 있는 PDF 21쪽을 추가했다.
  기존 표 근거인 22쪽도 유지했다.
- S0190·S0193·S0194의 후속 조사 단계와 원문에 명시된 세대 정보를 구조 필드에 보완했다.
  각각 10대 / 60대·10대 / 10대이며, 현대 사용 확률을 뜻하지 않는다.
- S0194의 `has_form` 목적어에 들어 있던 ‘10대 확인에서 사용 기록’이라는 설명문을
  실제 형태 `-지 않다`로 정리했다. 세대와 조사 맥락은 별도 필드로 옮겼다.
- 9건의 기계적으로 어색한 근거 요약 문장을 원문에 맞는 설명으로 다듬었다.
- 위 수정은 9건의 기존 ID를 유지한 필드 보완이다. Claim 추가·삭제는 없다.
- 페이지별 처리 기록과 사람이 읽는 검토 문서를 같은 장부에 맞춰 갱신했다.

현재 총량은 318건 그대로다. 후보 233 / 보류 37 / 맥락 전용 48, 사람 미검토 상태도 그대로다.

## 실행 기록·한계

1. 기본 권한 실행: DNS ENOTFOUND로 실패. 약 201.82초, CLI 보고 비용·사용량 0.
2. 외부 연결 권한을 받은 재시도: 내부 읽기 전용 bubblewrap을 유지해 성공. 약 207.30초.
3. CLI가 보고한 주 응답 모델은 `claude-sonnet-5`이며, `modelUsage`에는
   `claude-haiku-4-5-20251001` 호출도 함께 기록됐다. 이 보조 호출의 역할은 결과만으로 확정하지 않는다.
4. CLI 총 환산 비용은 약 $0.313371. Claude Team 로그인으로 실행했으며 실제 별도 청구액이나
   구독 잔여 한도를 의미하는 값은 아니다. 세부 토큰·모델 정보는 원 응답에 보존했다.
5. 결과는 JSON 코드펜스에 싸여 반환되어 처음 엄격 파싱에 실패했다. 바깥 코드펜스만 제거한 뒤
   체크포인트 ID와 대상 9건의 판정 집합을 검증했다. 원래 `envelope.result`는 수정하지 않았다.
   실행기에도 같은 제한적 처리를 추가했다. 파싱을 위해 추가 모델 호출은 하지 않았다.
