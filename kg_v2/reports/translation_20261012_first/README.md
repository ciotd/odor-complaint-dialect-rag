# KG v2 최초 연결 실행 — 보존된 개발 결과

이 폴더는 입력 분석·KG v2·생성기를 처음 연결해 실행한 38개 입력×4조건 결과다. 출력 검토에서 특정 표준어 형태를 전제로 하는 후보가 넓은 문법 기능 경로로 선택되는 문제가 발견됐다. 해당 조회 범위를 수정한 **[최종 실행·품질 진단](../translation_20261012/README.md)**을 함께 본다.

최초 출력과 요청은 덮어쓰지 않았다. 최종 실행에서는 요청이 완전히 동일한 KG 없음·기존 KG 성공 결과만 재사용했다. 이 폴더의 config는 당시 기존 개발 설정 템플릿을 포함하며, 실제 네 조건의 요청은 jobs.json을 따른다.
